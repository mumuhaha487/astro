<h1 id="unique_ptr%E6%8C%87%E9%92%88">unique_ptr指针</h1>

<p>开门见山</p>

<p>这一章节我们来了解unique指针</p>

<p>什么是unique_ptr指针</p>

<blockquote>
<p>unique_ptr是一种独占所有权的智能指针，同一时间只能有一个unique_ptr指向一个对象，当unique_ptr被销毁时，对象也会被释放。unique_ptr不能被复制，只能通过移动语义转移所有权。</p>
</blockquote>

<h2 id="unique%E7%9A%84%E7%89%B9%E7%82%B9">unique的特点</h2>

<ol><li>基于排他所有权模式——两个指针不能指向同一个资源</li>
	<li>无法进行左值unique_ptr复制构造，也无法进行左值复制赋值操作，但允许临时右值赋值构造和赋值，也就是让程序员明白这么做的后果</li>
	<li>保存指向某个对象的指针，当它本身离开作用域时会自动释放它指向的对象。</li>
	<li>在容器中保存指针是安全的</li>
</ol><h2 id="%E4%BE%8B%E5%AD%90">例子</h2>

<pre>
<code class="language-cpp">#include &lt;iostream&gt;
#include &lt;memory&gt;
#include &lt;vector&gt;
using namespace std;

int main()
{
	unique_ptr&lt;string&gt; p1(new string("hello"));
	unique_ptr&lt;string&gt; p2(new string("hi"));

	cout &lt;&lt; "p1：" &lt;&lt; p1.get() &lt;&lt; endl;
	cout &lt;&lt; "p2：" &lt;&lt; p2.get() &lt;&lt; endl;

	//p1 = p2;					// 禁止左值赋值
	//unique_ptr&lt;string&gt; p3(p2);	// 禁止左值赋值构造

	unique_ptr&lt;string&gt; p3(std::move(p1));
	p1 = std::move(p2);	// 使用move把左值转成右值就可以赋值了

	cout &lt;&lt; "p1 = p2 赋值后：" &lt;&lt; endl;
	cout &lt;&lt; "p1：" &lt;&lt; p1.get() &lt;&lt; endl;
	cout &lt;&lt; "p2：" &lt;&lt; p2.get() &lt;&lt; endl;

	return 0;
}</code></pre>

<pre>
<code class="language-cpp">p1：000002406200C750
p2：0000024062014CD0

p2：0000000000000000

按任意键关闭此窗口. . .</code></pre>

<p>在unique_ptr当中，p1=p2这样的赋值是非法的，不允许的</p>

<p>必须要用</p>

<pre>
<code class="language-cpp">unique_ptr&lt;string&gt; p3(std::move(p1));</code></pre>

<p>把p1的值赋值给p2，同时把p1的值给清空，这是符合我们的直觉的</p>

<p>这样可以让程序员清楚自己做了什么，防止报错时无法排查</p>

<h2 id="%E5%AE%B9%E5%99%A8%E4%B8%AD">容器中</h2>

<p>同理在容器中也是一样，这样也是不被允许的</p>

<pre>
<code class="language-cpp">vec[0] = vec[1];</code></pre>

<p>这样做才是正确的</p>

<pre>
<code class="language-cpp">vec[0] = std::move(vec[1]);	</code></pre>

<p>支持对象数组的内存管理</p>

<p>你在unique_ptr可以这样定义，而auto_ptr不行</p>

<pre>
<code class="language-cpp">unique_ptr&lt;char[]&gt; array(new char[10]);</code></pre>

<h2 id="%E6%9E%84%E9%80%A0%EF%BC%8C%E8%B5%8B%E5%80%BC%EF%BC%8C%E9%87%8A%E6%94%BE">构造，赋值，释放</h2>

<p>除此之外构造，赋值，释放都是和auto_ptr指针是一样的（具体可以查看上一节内容）</p>

<h1 id="auto_ptr%E4%BB%A5%E5%8F%8Aunique_ptr%E7%9A%84%E6%8E%92%E4%BB%96%E6%80%A7">auto_ptr以及unique_ptr的排他性</h1>

<pre>
<code class="language-cpp">auto_ptr&lt;string&gt; p1;
string *str = new string("abc");
p1.reset(str);	// p1托管str指针
auto_ptr&lt;string&gt; p2;
p2.reset(str);	
// 此时p1已经没有托管内容指针了，为NULL，在使用它就会内存报错！
cout &lt;&lt; "str：" &lt;&lt; *p1 &lt;&lt; endl;
</code></pre>

<p>在这之中开始时p1托管str的指针，后面p2接管str指针的同时会把p1的托管给取消，这样p1指针指向的就是NULL（空），从而报错。</p>

<p>这是因为auto_ptr与unique_ptr的排他性</p>
