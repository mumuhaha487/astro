<h1 id="%E9%A2%98%E7%9B%AE">题目</h1>

<blockquote>
<p>这天小明正在学数数。</p>

<p>他突然发现有些正整数的形状像一挫 “山”, 比如 123565321、145541123565321它 们左右对称 (回文) 且数位上的数字先单调不减, 后单调不增。</p>

<p>小朋数了衣久也没有数完, 他惒让你告诉他在区间 [2022,2022222022] 中有 多少个数的形状像一座 “山”。</p>
</blockquote>

<h1 id="%E8%A6%81%E6%B1%82">要求</h1>

<p>填空题，要写出答案即可</p>

<h1 id="%E6%80%9D%E8%B7%AF">思路</h1>

<h2 id="%E6%9A%B4%E5%8A%9B%E8%A7%A3%E6%B3%95">暴力解法</h2>

<p>思路非常简单，提取每一个数字的位数来判断两边是否相等，并且判断前一半是否是单调不减的</p>

<h4 id="%E7%BC%BA%E7%82%B9">缺点</h4>

<p>缺点是每一个都要计算会十分麻烦，计算量直接来到了10的10次方，估计要运行一分多钟，虽然题目只要求答案，你可以运行完成后直接打印答案，但是还有更加巧妙的思路</p>

<h2 id="%E6%8A%80%E5%B7%A7">技巧</h2>

<h3 id="%E4%B8%AD%E9%97%B4%E4%B8%80%E9%83%A8%E5%88%86">中间一部分</h3>

<p>由于1111~999999999可以进行变化</p>

<p>取前一半数字，只要他满足单调不减就行了</p>

<p>比如如果五位数</p>

<p>取前一半也就是三个数字</p>

<p>124时，后面必定有且只有一种数字（21）与其对应，形成12421</p>

<p>所以我们只需算前一半的数字即可</p>

<p>也就是11~99999</p>

<p>这一个变化带来速度提升是巨大的</p>

<p>时间直接缩小几个数量级</p>

<h3 id="%E6%9C%AB%E5%B0%BE%E4%B8%80%E9%83%A8%E5%88%86">末尾一部分</h3>

<p>在末尾中2022222022这个数字比较特殊</p>

<p>因为开头为2所以前一位也必须不比2小的数</p>

<p>显然2后面是0无法满足条件</p>

<p>所以最高位2必须要变小，然而不能为0</p>

<p>所以只能是1（个位同时也必须是1），而且中间部分位数可以随便变化（因为1111111111~1999999991属于2022~2022222022）</p>

<p>于是可以把他看成为8位数字，然后再算一次加起来就行了</p>

<h3 id="%E5%BC%80%E5%A4%B4%E4%B8%80%E9%83%A8%E5%88%86">开头一部分</h3>

<p>开头没什么好说的</p>

<p>2022~9999</p>

<p>提取前一半位数，同时由于最小为2，所以百位也必须是不比2小的数字（2,3,4,5,6,7,8,9）</p>

<p>以此类推可以心算出来开头部分（2022~9999）的符合条件的个数为8+7+6+5+4+3+2+1</p>

<h3 id="%E6%9C%80%E5%90%8E">最后</h3>

<p>最后全部加起来</p>

<h1 id="%E4%BB%A3%E7%A0%81%E9%83%A8%E5%88%86">代码部分讲解</h1>

<p>中间一部分加末尾一部分为</p>

<pre>
<code class="language-cpp">       int sum_2 = 0;
        int sum_3 = 0;
        int sum_4 = 0;

        else

            sum_3 = sum_3 + 1*pow(10, j);

        {
            if (Function_1(z))
            {
                max++;
            }
        }</code></pre>

<p> 由于奇数位数的数字取一半用的是进一法，而c/c++用的是退一法，所以对奇数位数的数字做出分类以及改变</p>

<p>其中pow代表的是指数公式（前面为底数，后面为指数），sum3和sum4分别表示各个位数的值的最大和最小值，方便通过访问来遍历数组的元素</p>

<p>当位数个数为10个时也就是到了“末尾一部分”的数字了</p>

<p>这时候可以直接当做8，当成8位数来计算就可以了</p>
