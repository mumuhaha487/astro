<h1 id="%E9%A2%98%E7%9B%AE">题目</h1>

<blockquote>
<p>给定一个长度为 <code>n</code> 的整数数组 <code>height</code> 。有 <code>n</code> 条垂线，第 <code>i</code> 条线的两个端点是 <code>(i, 0)</code> 和 <code>(i, height[i])</code> 。</p>

<p>找出其中的两条线，使得它们与 <code>x</code> 轴共同构成的容器可以容纳最多的水。</p>

<p>返回容器可以储存的最大水量。</p>

<p><strong>说明：</strong>你不能倾斜容器。</p>
</blockquote>

<p></p>

<blockquote>
<pre>
<strong>输入：</strong>[1,8,6,2,5,4,8,3,7]
<strong>输出：</strong>49 
<strong>解释：</strong>图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。</pre>
</blockquote>

<h1 id="%E9%A2%98%E7%9B%AE%E5%88%9D%E6%AD%A5%E8%A7%A3%E6%9E%90">题目初步解析</h1>

<p>这一道题就是我们小时候常常说的水桶效应</p>

<h2 id="%E6%B0%B4%E6%A1%B6%E6%95%88%E5%BA%94">水桶效应</h2>

<blockquote>
<p>水桶效应是指一只水桶想盛满水，必须每块木板都一样平齐且无破损，如果这只桶的木板中有一块不齐或者某块木板下面有破洞，这只桶就无法盛满水。是说一只水桶能盛多少水，并不取决于最长的那块木板，而是取决于最短的那块木板。也可称为短板效应。一个水桶无论有多高，它盛水的高度取决于其中最低的那块木板。</p>
</blockquote>

<p>这就是我们要利用的思想来解答题目</p>

<h1 id="%E4%BB%A3%E7%A0%81%E5%AE%9E%E7%8E%B0%E9%80%BB%E8%BE%91">代码实现逻辑</h1>

<p>这是一个运用到双指针思想的问题（不一定用指针）</p>

<h2 id="%E7%AC%AC%E4%B8%80%E6%AD%A5">第一步</h2>

<p>可以在数组的两侧（开头以及末尾）标记两个指针（或者记录下标）</p>

<p>然后计算面积</p>

<h2 id="%E7%AC%AC%E4%BA%8C%E6%AD%A5">第二步</h2>

<p>此时当然不能说这是最大的面积</p>

<p>我们要进行遍历</p>

<p>那怎么遍历呢？</p>

<p>还记得我们刚刚说的木头效应吗？</p>

<p>你装下的水取决于的是你最小的那一块木板</p>

<p>那如果要遍历的话</p>

<p>只能是短的一边进行更新，如果是左边的指针那就往右移动</p>

<p>如果是右边的就往左边进行移动</p>

<p>也就是都向“中间”更新</p>

<p></p>

<p><img alt="" height="307" src="/image/5bd674cc9eaf51086022413ec1013881.png" width="573" /></p>

<p></p>

<p><span style="color:#fe2c24;">因为在横坐标两条垂线的距离降低的情况下，如果变化的是长边，盛水的长方形的高依旧不会变，不需要比较，那么面积必然会更小</span></p>

<h2 id="%E7%AC%AC%E4%B8%89%E6%AD%A5">第三步</h2>

<p>那迭代出来的面积个数不止一个，怎么办呢？</p>

<p>分别比大小就可以了</p>

<p>第三步的步骤就是把每次迭代出来的值与之前的最大值比大小</p>

<p>如果更新的值更大，那就更新最大值就行</p>

<h1 id="%E4%BB%A3%E7%A0%81%E5%85%B7%E4%BD%93%E5%AE%9E%E7%8E%B0">代码具体实现</h1>

<h2 id="%E6%B3%A8%E6%84%8F">注意</h2>

<p>这里是展示所有代码可直接运行，但是力扣上的一个类，所以要改一下才可以跑</p>

<h2 id="%E6%B7%BB%E5%8A%A0%E5%AE%B9%E5%99%A8%E5%85%83%E7%B4%A0%E7%9A%84%E5%87%BD%E6%95%B0">添加容器元素的函数</h2>

<pre>

<p> 这里就是最基本的赋值就行</p>

<p>可以用链表的形式，当然我图方便用了容器</p>

<p>不过如果用链表的话那下面的函数要进行修改</p>

<p>这些方法都可以</p>

<h2 id="%E8%AE%A1%E7%AE%97%E8%BF%AD%E4%BB%A3%E5%B9%B6%E4%B8%94%E5%88%A4%E6%96%AD%E9%9D%A2%E7%A7%AF%E6%98%AF%E5%90%A6%E6%98%AF%E6%9C%80%E5%A4%A7%E5%80%BC">计算迭代并且判断面积是否是最大值</h2>

<pre>
<code class="language-cpp">int maxArea(vector&lt;int&gt; height) 
{
	int maxarea = 0;
	int maxarea_1 = 0;
	int i = 0;
	int j = height.size() - 1;
	//最左节点
	int left_str = height[i];
	//最右节点
	int right_str = height[j];
	while (i != j)
	{
		if (height[i] &lt; height[j])
		{
			maxarea_1 = height[i] * (j - i);
			if (maxarea &lt; maxarea_1)
				maxarea = maxarea_1;
			i++;
		}
		else
		{
			maxarea_1 = height[j] * (j - i);
			if (maxarea &lt; maxarea_1)
				maxarea = maxarea_1;
			j--;
		}
	}
	return maxarea;
}</code></pre>

<p>我这里是用下标进行定位的</p>

<p>计算面积同时判断大小</p>

<p>while语句中判断左边标记的下标等于右边的时候跳出循环</p>

<p><span style="color:#ffd900;"><span style="background-color:#fe2c24;">需要注意的是迭代的时候左边是++右边是--</span></span></p>
