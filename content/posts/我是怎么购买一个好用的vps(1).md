# 前言

博主接触VPS应该是很早很早之前了，大概可能在大二的时候就开始看服务器了，当时还不是自己买的，好像是阿里云大学生活动送的8个月的服务器，带宽是5兆，1核1G的。

当时我就想着这个带宽也太小了。当时我本来还打算在这个服务器上部署WordPress。但是结果可想而知，一个是性能太差了。WordPress 是动态博客，依赖于 PHP 数据库，所以对性能的开销会非常大。一核 1G + 5 兆带宽，点开一个博客都要加载半年，所以后面还是换成家庭的物理服务器加内网穿透去解决。

然后大三大四之后，我就查看国外的服务器。当时看了一台国外的服务器，1G带宽只需要70\~80块钱一年，当时就别提有多兴奋了，说这么大的带宽用起来一定很舒服吧。性能开销低不要紧，我只需要搞个内网穿透就行了。结果可能也能猜到了，70\~80块钱的服务器，能是什么好的东西？穿透起来打开速度特别特别慢，甚至不如我的 Cloudflare 穿透IPv6 的。

后面我在想，ping了一下它那个服务器，我发现那个服务器的延迟非常高，200ms到300ms，我就想着应该是延迟的问题。（当时没注意丢包率，只发现延时很高。其实丢包率那时候也高，但是没注意到。）

然后我想着延迟高，那我买个延迟低的。延迟要低，不应该距离越近延迟越低吗？当然，道理是这样子没错的。但是当时没想到，延迟低的距离一定近，距离近的延迟不一定低，它会绕路。然后我就买了一个台湾的服务器，结果可想而知，ping了一下，发现比之前美国的服务器延迟还高。后面查到它不是直连大陆内部的，而是绕美国之后再回中。也就是说，它还多绕一个美国的路线，很抽象。

# 初窥门径

当时我就想着，应该是有什么网络优化的吧，然后我就在网上搜测评帖子。

# 柳暗花明

本来后面我都放弃了，觉得国外的服务器买不得，要买只能用阿里云或者腾讯云这种小带宽的机器，要么就是用内网穿透或者Cloudflare的ipv6转v4的cdn功能，但是在一次偶然的机会我认识到了线路，于是新的知识也在我的脑海中形成。

# 恶补知识

首先我发现，vps在国内到国外（以及国外到国内）的时候，对于速度影响最大的就是进入内地的线路，有些vps不会直接直连到内地，比如我上面说的那一台vps，它没有直连中国大陆的线路，那怎么办呢？

凑巧，它有直连美国的线路，而美国有回国的线路，所以有些线路不好的vps会直接绕道美国后在回国，基本功就是绕地球一圈，而这种价格低的机器一般采用的骨干网的线路，而这种机子其他的还好，一到高峰期（晚上六点之后），由于晚上用网的人多了起来，运营商当然会考虑国内互连的使用体验，所以你的便宜vps在晚高峰的时候可用性会更差。

好比就是要过年了，回家的人多了，路上堵车了，那有办法可以规避呢？毕竟我看到也有很多网站他可以在晚上和白天一样正常打开，这个时候就是我们要讲的——优化线路。

如果把骨干网比作国道，那么优化线路就不恰当的比作成高速公路，但是这个高速公路主要不是快，而是走的人少，为什么走的人少，很简单，因为它要很多钱。所以，可以确切的说，贵的vps不一定是优化线路，但是便宜的一到不是优化线路，现在普遍三网优化的2h2g500g机器一年的钱基本上300左右，再低也低不到很多很多了。

好，话回到这里，那这一条高速通道也分单程和双程，在线路术语上被叫做去程和回程。有些是去程普通线路（骨干网），回程优化。

好的，先别急着说不是双程优化线路的机器我用起来难受😂。价格只要够低明确好自己的需求，单程便宜的机器也不是不能用，首先你要明确你的使用场景，我们需要知道如果你需要在服务器上部署网页，一般是用户向服务器发送请求（数据量非常少可以几乎不计），然后服务器处理请求后发送相应的html，js，css，wolf等等等等文件（这一部分的请求流量很大）好的，那如果你要搭建网页，硬要叫你选是选回程还是去程。。。。包是回程的话，因为你是要从网页端拿数据的，发送请求的数据很少，优化线路的大带宽稳定链接需求很少。

那第二个情况，我只想要有个大带宽的公网ip的服务器做内网穿透，我可以买单程优化的吗。。。回答这种问题之前我们不妨看看服务器的请求流程。需要直接的是这里国内到国外统称去程，国外到国内统称回程，不以服务器判断，比如我的家庭服务器向美国服务器发送数据按理来说对于美国服务器来说是回程，但是，从我们这边来看是去程。来，现在我们整理一下全套链路。

用户向美国frp服务器发送请求（去程，流量小）->美国frp服务器向国内家庭服务器透传用户的请求（回程，流量小）->国内家庭服务器向美国frp服务器回复相应的资源文件（去程，流量大）->美国frp服务器向客户回复资源文件（回程流量大）



我们可以注意到这一套链路中回程和去程同样重要，故如果是当frp机器用，不能只买单程优化的vps。



# 总结

在购买vps的时候，带宽固然很重要，但是线路才是当中最重要的，好的线路机哪怕只有40m带宽也要比1Gps带宽的vps的实际体验要好更多。那有聪明的人可能会说了，那我不知道什么是优化线路，优化线路有哪些，别急，这一篇太长了，我下一篇再写。
