<h1 id="%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%E4%BD%BF%E7%94%A8%E6%99%BA%E8%83%BD%E6%8C%87%E9%92%88">为什么要使用智能指针</h1>

<blockquote>
<p>使用智能指针的主要目的是管理动态分配的内存，以确保在不再需要时正确释放内存，避免内存泄漏和悬挂指针等问题。</p>
</blockquote>

<h1 id="%E6%99%BA%E8%83%BD%E6%8C%87%E9%92%88%E7%9A%84%E4%BD%9C%E7%94%A8">智能指针的作用</h1>

<blockquote>
<p>智能指针是一种封装了原始指针的对象，它提供了自动内存管理的功能。与传统的裸指针相比，智能指针具有以下优势：</p>

<ol><li>
	<p>自动释放内存：智能指针使用了RAII（资源获取即初始化）的原则，在创建时分配内存，在销毁时自动释放内存，无需手动管理内存释放，避免了因为忘记释放内存而造成的内存泄漏问题。</p>
	</li>
	<li>
	<p>避免悬挂指针：智能指针会在其所管理的对象不再需要时自动释放内存，并将指针置为空，避免了悬挂指针问题，即指向已经释放的内存区域。</p>
	</li>
	<li>
	<p>异常安全：智能指针可以确保在发生异常时正确释放资源，因为它们的析构函数会在对象被销毁时自动调用。</p>
	</li>
	<li>
	<p>方便易用：智能指针提供了类似于原始指针的操作符重载，使得使用起来更加方便和直观。</p>
	</li>
</ol><p>总之，使用智能指针可以提高代码的可靠性和安全性，并减少手动管理内存的工作量，是现代C++编程中推荐的做法。</p>
</blockquote>

<h2 id="%E4%B8%BE%E4%B8%AA%E4%BE%8B%E5%AD%90">举个例子</h2>

<pre>
<code class="language-cpp">#include &lt;iostream&gt;
#include &lt;memory&gt;
#include &lt;vector&gt;
using namespace std;
void Function_1()
{
	int *a=new int;
	*a = 12;
	//省略其他代码
	if (true)
	{
		return;
		//此时已经跳出循环所以不执行下面的删除指针a
	}
	delete a;
}
int main()
{
	Function_1();
	//这时a指针没有被释放
	return 0;
}</code></pre>

<p>这个时候在执行程序的这一过程中a指针没有被及时释放，这只是一个简单的例子，</p>

<p>在真实的情况中也不会只有这一个a没有被释放，甚至在一些循环中如果释放指针那造成的结果是灾难性的，你排除一些报错会十分的困难。</p>

<p>每次记住及时释放指针是一个好习惯并且也是一个好的解决办法。但是这是十分困难的</p>

<p>这个时候就可以使用智能指针这个方案</p>

<h1 id="%E6%9C%80%E5%BC%80%E5%A7%8B%E4%BD%BF%E7%94%A8%E7%9A%84%E6%99%BA%E8%83%BD%E6%8C%87%E9%92%88%E2%80%94%E2%80%94auto_ptr">最开始使用的智能指针——auto_ptr</h1>

<blockquote>
<p>auto_ptr 是c++ 98定义的智能指针模板，其定义了管理指针的对象，可以将new 获得（直接或间接）的地址赋给这种对象。当对象过期时，其析构函数将使用delete 来释放内存！</p>
</blockquote>

<h2 id="%E4%BD%BF%E7%94%A8%E6%96%B9%E6%B3%95">使用方法</h2>

<p>在使用之前需要在头文件中定义</p>

<pre>
<code class="language-cpp"> #include &lt; memory &gt;</code></pre>

<p>用法为</p>

<blockquote>
<p>auto_ptr&lt;类型&gt; 变量名(new 类型)</p>
</blockquote>

<h3>举个例子</h3>

<pre>
<code class="language-cpp">auto_ptr&lt;int&gt; sum(new int(20));//这是定义一个int类型的智能指针
auto_ptr&lt; string &gt; str(new string("你好，我叫mumuemhaha"));//这是定义一个string类型的智能指针
</code></pre>

<h3 id="%E8%BF%9B%E9%98%B6%E4%BD%BF%E7%94%A8">进阶使用</h3>

<p>到这里想必你已经可以理解auto_ptr如何定义了</p>

<p>我们再次把难度稍微提升一些</p>

<p>这时我们调用第一个类</p>

<pre>
<code class="language-cpp">#include &lt;iostream&gt;
#include &lt;memory&gt;
#include &lt;vector&gt;
using namespace std;
class Test_1 {
public:
	Test_1() { cout &lt;&lt; "Test_1的构造函数" &lt;&lt; endl; }
	~Test_1() { cout &lt;&lt; "Test_1的析构函数" &lt;&lt; endl; }

	int getsum() { return this-&gt;sum; }

private:
	int sum = 20;
};

{
	Test_1* test_1 = new Test_1;
	return 0;
}</code></pre>

按任意键关闭此窗口. . .</code></pre>

<p>这时你会发现只有构造函数没有析构函数，这时因为test_1已经被a托管了，如果需要释放必须要手动释放（或者用另外一个智能指针去托管它）</p>

<h2 id="reset()%20%E9%87%8D%E7%BD%AE%E6%99%BA%E8%83%BD%E6%8C%87%E9%92%88%E6%89%98%E7%AE%A1%E7%9A%84%E5%86%85%E5%AD%98%E5%9C%B0%E5%9D%80%EF%BC%8C%E5%A6%82%E6%9E%9C%E5%9C%B0%E5%9D%80%E4%B8%8D%E4%B8%80%E8%87%B4%EF%BC%8C%E5%8E%9F%E6%9D%A5%E7%9A%84%E4%BC%9A%E8%A2%AB%E6%9E%90%E6%9E%84%E6%8E%89"><strong>reset</strong>() 重置智能指针托管的内存地址，如果地址不一致，原来的会被析构掉</h2>

<p>这个不举例子了就是重置指针,注意的是其中可以"变量.reset()”也可以"变量.reset(new Test_1)”</p>

<h2 id="%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9">注意事项</h2>

<ul><li>尽量不要把auto_ptr指针定义为全局变量或者指针（这将与其他指针相比毫无意义）</li>
	<li>除非你知道后果，否则不要把auto_ptr 智能指针赋值给同类型的另外一个智能指针比如像这样</li>
	<li>
	<pre>
<code class="language-cpp">auto_ptr&lt;Test_1&gt; t1(new Test);
auto_ptr&lt;Test_1&gt; t2(new Test);
t1 = t2;	// 不要这样</code></pre>
	</li>
</ul><h1 id="auto_ptr%E7%9A%84%E7%BC%BA%E7%82%B9%E4%BB%A5%E5%8F%8A%E4%B8%BA%E4%BB%80%E4%B9%88%E5%9C%A8C%2B%2B11%E4%B8%AD%E8%A2%AB%E6%B7%98%E6%B1%B0">auto_ptr的缺点以及为什么在C++11中被淘汰</h1>

<p>一        在第二个注意事项中，因为t1=t2这个表达式就是t2指针指向数据的所有权转换给t1，并且把把t2的指针清空.这个和我平时的直觉不相符</p>

<p></p>

<p>二        正是这个原因，所以最好也不要在STL容器中使用auto_ptr指针（因为容器的值必须要支持可以赋值）</p>

<p></p>

<p>三        不支持对象数组的内存管理，比如</p>

<pre>
<code class="language-cpp">auto_ptr&lt;int[]&gt; array(new int[5]);</code></pre>

<p>所以，C++11以及之后使用了接下来要讲的更严谨的unique_ptr 来去取代了auto_ptr！</p>
