<code>MIN=1e-9            #一个足够小的数

import numpy as np
def f_yuan(x_2):
    y_2=x_2**2        #这里的函数可以改
    return y_2
def F_daoshu_yuan(x_1):
    a_1=(f_yuan(x_1+MIN)-f_yuan(x_1))/MIN
    return a_1

A_1=F_daoshu_yuan(1)

<h1>优缺点</h1>

<p>优点是泛用性非常好，也十分好理解，在合适的范围，函数可以变得不规则，但是依旧可以求出导数的大约值，并不会与真实值差的很多</p>

<p></p>

<p>缺点很明显在数据十分大的时候误差也会越来越大，原因就是MIN的值还是太大了。</p>
