<h1 id="%E9%A2%98%E7%9B%AE">题目</h1>

<blockquote>
<p>把 2019 分解成 3 个各不相同的正整数之和，并且要求每个正整数都不包含数字 2 和 4，一共有多少种不同的分解方法？</p>

<p>注意交换 3 个整数的顺序被视为同一种方法，例如 1000+1001+18 和 1001+1000+18 被视为同一种。</p>
</blockquote>

<h1 id="%E8%A6%81%E6%B1%82">要求</h1>

<p>这是一道结果填空的题，你只需要算出结果后提交即可</p>

<h1 id="%E6%80%9D%E8%B7%AF">思路</h1>

<p>思路很简单——穷举每一个数字</p>

<p><span style="color:#f9eda6;"><span style="background-color:#fe2c24;">每个正整数都不包含数字 2 和 4</span></span>就把各个位数的千位百位十位各位提取出来分别判断</p>

<pre>
<code class="language-cpp">bool Panduan(int n)
{
	int a = n / 1000;
	int b = (n - a * 1000) / 100;
	int c = (n - a * 1000 - b * 100) / 10;
	int d = n % 10;
	if (a == 2 || a == 4 || b == 2 || b == 4 || c == 2 || c == 4 || d == 2 || d == 4)
	{
		return false;
	}
	else
	{
		return true;
	}
}</code></pre>

<p><span style="color:#ffd900;"><span style="background-color:#fe2c24;">关于筛选只是顺序不同的数字</span></span>可以固定大小比如三个数字x,y,z固定x&gt;y&gt;z这样就不会因为顺序不一样，造成多算出来结果</p>

<h1 id="%E6%9C%80%E5%90%8E%E7%9A%84%E4%BB%A3%E7%A0%81">最后的代码</h1>

<p>就是</p>

<pre>
<code class="language-cpp">#include &lt;iostream&gt;
using namespace std;
int sum_1 = 2019;
bool Panduan(int n)
{
	int a = n / 1000;
	int b = (n - a * 1000) / 100;
	int c = (n - a * 1000 - b * 100) / 10;
	int d = n % 10;
	if (a == 2 || a == 4 || b == 2 || b == 4 || c == 2 || c == 4 || d == 2 || d == 4)
	{
		return false;
	}
	else
	{
		return true;
	}
}
int main()
{
	int sum_max = 0;
	for (int i = 1; i&lt;2019 ;i++)
	{
		for (int j = i+1; j &lt; sum_1 - i; j++)
		{
			int z = sum_1 - i - j;
			if (i == z || z == j || j &gt;= z)
			{
				continue;
			}
			if (Panduan(i) &amp;&amp; Panduan(j) &amp;&amp; Panduan(z))
			{
				sum_max++;
			}
			else
			{
				continue;
			}
		}
	}
	cout &lt;&lt; sum_max &lt;&lt; endl;
    return 0;
}</code></pre>
