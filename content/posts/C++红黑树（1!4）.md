<h1 id="%E7%BA%A2%E9%BB%91%E6%A0%91%E7%9A%84%E4%BC%98%E7%82%B9%E4%BB%A5%E5%8F%8A%E7%89%B9%E7%82%B9">红黑树的优点以及特点</h1>

<p></p>

<blockquote>
<p>红黑树是一种自平衡二叉查找树，它能够保证在最坏情况下基本动态集合操作（插入、删除、查找）的时间复杂度为O(log n)。红黑树通过在每个节点上增加一个存储位来表示节点的颜色，可以将树保持黑平衡，具体来说就是满足任何一条从根到叶子节点的路径上的黑节点数量相等。红黑树的性质包括：根节点是黑色的；每个叶子节点都是黑色的空节点；如果一个节点是红色的，则它的两个子节点都是黑色的；任意一节点到其每个叶子的所有路径都包含相同数目的黑色节点。这些性质保证了红黑树的平衡性和查找效率。</p>
</blockquote>

<h1 id="%E4%B8%BA%E4%BB%80%E4%B9%88%E8%A6%81%E4%BD%BF%E7%94%A8c%2B%2B%E6%9D%A5%E5%88%9B%E5%BB%BA%E7%BA%A2%E9%BB%91%E6%A0%91">为什么要使用c++来创建红黑树</h1>

<blockquote>
<p>C++ 使用红黑树是为了保证数据结构的平衡和高效地支持插入、删除、查找等操作。红黑树也是关联容器 map 和 set 的底层实现之一。并且可以更好的理解指针和逻辑思维能力。</p>

<p>并且相对于二叉树和其他树，红黑树可以实现相对更快的查找</p>

<p>但是相对于其他的树，它的平衡性调整会比较繁琐也比较难理解</p>
</blockquote>

<h1 id="%E7%BA%A2%E9%BB%91%E6%A0%91%E7%9A%84%E5%AE%9A%E4%B9%89%2F%E7%89%B9%E6%80%A7">红黑树的定义/特性</h1>

<ul><li>红黑树只会出现红色节点以及黑色节点且根节点一定是黑色</li>
	<li></li>
	<li>所有叶子节点到根节点所经过的黑色节点一定相同</li>
	<li>最短路径的两倍不会超过最长路径</li>
</ul><p></p>

<h1 id="%E4%BB%A3%E7%A0%81">代码</h1>

<p>则我们可以看到写出c++/c的代码</p>

<pre>
<code class="language-cpp">#include &lt;iostream&gt;
using namespace std;
enum Colour//定义一个颜色
{
	RED,
	BLACK,
};
template&lt;typename T&gt;//定义一个模版T
struct RBNode//一个节点的结构体
{
	RBNode* lchild,
		* rchild,
		* parent;
	T	data;
	Colour colour=RED;//初始化为RED也可以后面定义一个初始化函数
};

template &lt;typename T&gt;//再定义一个模版T（template只能联系到下面一句语句）
class RBTree//树
{
public:
	RBTree()
	{
		root = nullptr;
	}
	~RBTree()
	{
		ReleaseNode(root);
	}
private:
	void ReleaseNode(RBNode&lt;T&gt;* pnode)//删除节点，释放内存
	{
		if (pnode != nullptr)
		{
			ReleaseNode(pnode-&gt;lchild);
			ReleaseNode(pnode-&gt;rchild);
		}
		delete pnode;
	}
private:
	RBNode &lt;T&gt;* root;//根节点
};

int main()
{
	printf("OK");//还没有到定义的时候
	return 0;
}</code></pre>

<p></p>

<p>如图，其实到目前为止定义一个红黑树以及初始化和普通的二叉树并没有什么区别。</p>

<p>但是我们已经把大致的框架搭建出来</p>

<p>接下来要做的就是插入数据的平衡性调整</p>

<h2 id="%E4%B8%BA%E4%BB%80%E4%B9%88%E6%96%B0%E5%AE%9A%E4%B9%89%E7%9A%84%E5%8F%B6%E5%AD%90%E7%BB%93%E7%82%B9%E7%9A%84%E5%88%9D%E5%A7%8B%E5%80%BC%E4%B8%BA%E7%BA%A2%E8%89%B2%E8%80%8C%E4%B8%8D%E4%B8%BA%E9%BB%91%E8%89%B2">解释一下为什么新定义的叶子结点的初始值为红色而不为黑色</h2>

<blockquote>
<p>这里需要主要注意为什么新定义的叶子结点的初始值为红色而不为黑色</p>

<p>因为如果为黑色，<span style="background-color:#38d8f0;">由于红黑树的第三条特性，没插入之前红黑树各个的叶子结点已保持了平衡</span></p>

<p><span style="background-color:#38d8f0;">而插入数据之后平衡一定会被打破</span></p>

<p>从而造成每次插入数据之后都要进行一次平衡性调整平衡性调整的概率为100%</p>

<p>而如果红色只会在父亲节点为红色是因为第二条特性要进行平衡性调整，<span style="background-color:#38d8f0;">而在父亲节点为黑色时则直接插入</span>，无需进行平衡性调整。</p>
</blockquote>
