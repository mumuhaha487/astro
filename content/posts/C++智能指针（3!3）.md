<h1 id="share_ptr%E7%94%A8%E6%B3%95">share_ptr用法</h1>

<blockquote>
<p>shared_ptr使用引用计数的方式来管理资源，即每个shared_ptr对象都有一个关联的计数器，记录有多少个shared_ptr对象共享同一块内存资源。当计数器为0时，资源会被自动释放。</p>

<p></p>

<p>当复制或拷贝时，<strong>引用计数</strong>加1，当智能指针析构时，<strong>引用计数</strong>减1，如果计数为零，代表已经没有指针指向这块内存，那么我们就释放它！这就是 shared_ptr 采用的策略！</p>
</blockquote>

<pre>
<code class="language-cpp">class Person {

		this-&gt;no = v;

	int no;
};</code></pre>

<h2 id="%E4%B8%BB%E5%87%BD%E6%95%B0%E4%BB%A3%E7%A0%81">主函数代码</h2>

<pre>
<code class="language-cpp">int main()
{
    //定义两个share指针同时第二个由于已经构造好了，引用次数+1
	shared_ptr&lt;Person&gt; sp1;

	shared_ptr&lt;Person&gt; sp2(new Person(2));

	// 获取智能指针管控的共享指针的数量	use_count()：引用计数
	cout &lt;&lt; "sp1引用计数 = " &lt;&lt; sp1.use_count() &lt;&lt; endl;
	cout &lt;&lt; "sp2引用计数 = " &lt;&lt; sp2.use_count() &lt;&lt; endl &lt;&lt; endl;

	// 共享同时也共享引用次数
	sp1 = sp2;
    //打印出来引用次数同时验证猜想
	cout &lt;&lt; "sp1引用计数 = " &lt;&lt; sp1.use_count() &lt;&lt; endl;
	cout &lt;&lt; "sp2引用计数 = " &lt;&lt; sp2.use_count() &lt;&lt; endl &lt;&lt; endl;
    
	shared_ptr&lt;Person&gt; sp3(sp1);
	cout &lt;&lt; "sp1引用计数 = " &lt;&lt; sp1.use_count() &lt;&lt; endl;
	cout &lt;&lt; "sp2引用计数 = " &lt;&lt; sp2.use_count() &lt;&lt; endl;
	cout &lt;&lt; "sp2引用计数 = " &lt;&lt; sp3.use_count() &lt;&lt; endl &lt;&lt; endl;

	return 0;
}</code></pre>

<h3 id="%E9%87%8D%E7%BD%AE%E6%8C%87%E9%92%88">重置指针</h3>

<blockquote>
<p>p.reset() ; 将p重置为空指针，所管理对象引用计数 减1<br />

<h1 id="share_ptr%E4%BD%BF%E7%94%A8%E9%99%B7%E9%98%B1">share_ptr使用陷阱</h1>

<p>小心因循环引用造成无法释放资源!</p>

<p>如下代码：<br />
Boy类中有Girl的智能指针；<br />
Girl类中有Boy的智能指针；<br />
当他们交叉互相持有对方的管理对象时…（借用大佬写的代码）</p>

<pre>
<code class="language-cpp">#include &lt;iostream&gt;
#include &lt;string&gt;
#include &lt;memory&gt;

using namespace std;

class Girl;

class Boy {
public:
	Boy() {
		cout &lt;&lt; "Boy 构造函数" &lt;&lt; endl;
	}

	~Boy() {
		cout &lt;&lt; "~Boy 析构函数" &lt;&lt; endl;
	}

	void setGirlFriend(shared_ptr&lt;Girl&gt; _girlFriend) {
		this-&gt;girlFriend = _girlFriend;
	}

private:
	shared_ptr&lt;Girl&gt; girlFriend;
};

class Girl {
public:
	Girl() {
		cout &lt;&lt; "Girl 构造函数" &lt;&lt; endl;
	}

	~Girl() {
		cout &lt;&lt; "~Girl 析构函数" &lt;&lt; endl;
	}

	void setBoyFriend(shared_ptr&lt;Boy&gt; _boyFriend) {
		this-&gt;boyFriend = _boyFriend;
	}

private:
	shared_ptr&lt;Boy&gt; boyFriend;
};


void useTrap() {
	shared_ptr&lt;Boy&gt; spBoy(new Boy());
	shared_ptr&lt;Girl&gt; spGirl(new Girl());

	// 陷阱用法
	spBoy-&gt;setGirlFriend(spGirl);
	spGirl-&gt;setBoyFriend(spBoy);
	// 此时boy和girl的引用计数都是2
}


int main(void) {
	useTrap();

	system("pause");
	return 0;
}
</code></pre>

<p>这里是一个boy里有个girl的指针，而girl里也有个boy的指针</p>

<p>到最后</p>

<pre>
<code class="language-cpp">Boy 构造函数
Girl 构造函数
请按任意键继续. . .</code></pre>

<p>空间都没有释放出来（没有析构函数）</p>

<h2 id="%E5%8E%9F%E5%9B%A0">原因</h2>

<p><img alt="" height="889" src="/image/6468abd3f37a34fac8236b6c62b5364b.png" width="1200" /></p>

<p> 这里由于都各有对方的类，故引用计数为2</p>

<p>但是当程序结束的时候</p>

<p><img alt="" height="990" src="/image/c40339c100a9622567ea6e98d9ffc6ad.png" width="1200" /></p>

<p> 函数中的智能指针清理掉了，但是类中嵌套的智能指针无法释放，所有类无法调用析构函数</p>

<h2 id="%E8%A7%A3%E5%86%B3%E5%8A%9E%E6%B3%95%E4%B9%8B%E4%B8%80">解决办法之一</h2>

<p>如果不用两个类中的指针互相关联，而是一方单方面获得管理对方的共享指针，这样可以正常释放</p>

<p>假设还是上面的那个例子</p>

<p>由于因为开始释放boy是引用次数为2，函数结束计数减一变为一</p>

<p>之后开始释放girl，girl引用次数为1，函数结束计数减一变为零</p>

<p>这是开始析构girl，同时就会把boy类也析构掉，计数再次减一</p>

<p>这是boy引用次数为零，则boy也开始析构了</p>

<pre>
<code class="language-cpp">void useTrap() {
	shared_ptr&lt;Boy&gt; spBoy(new Boy());
	shared_ptr&lt;Girl&gt; spGirl(new Girl());

	// 单方获得管理
	//spBoy-&gt;setGirlFriend(spGirl);
	spGirl-&gt;setBoyFriend(spBoy);	
}
</code></pre>

<h1 id="weak_ptr%E6%99%BA%E8%83%BD%E6%8C%87%E9%92%88%EF%BC%88%E5%BC%B1%E6%8C%87%E9%92%88%EF%BC%89">weak_ptr智能指针（弱指针）</h1>

<blockquote>
<p>weak_ptr 设计的目的是为配合 shared_ptr 而引入的一种智能指针来协助 shared_ptr 工作, 它只可以从一个 shared_ptr 或另一个 weak_ptr 对象构造, 它的构造和析构不会引起引用记数的增加或减少。 同时weak_ptr 没有重载*和-&gt;但可以使用 lock 获得一个可用的 shared_ptr 对象。</p>
</blockquote>

<h2 id="weak%E6%99%BA%E8%83%BD%E6%8C%87%E9%92%88%E7%9A%84%E7%94%A8%E6%B3%95">weak智能指针的用法</h2>

<p>weak_ptr的定义空指针(weak_ptr &lt;T&gt;  a)和共享构造(weak_ptr &lt;T&gt; a(b)以及允许共享指针赋值给弱指针（a=b）都和其他智能指针差不多</p>

<p>同时和share_ptr一样可以用 .count()来查看引用次数</p>

<h2 id="%E6%B3%A8%E6%84%8F">注意</h2>

<p>弱指针不支持 * 和 -&gt; 对指针的访问</p>

<h2 id="%E5%BC%B1%E6%8C%87%E9%92%88%E5%88%B0%E5%85%B1%E4%BA%AB%E6%8C%87%E9%92%88%E7%9A%84%E8%BD%AC%E5%8C%96">弱指针到共享指针的转化</h2>

<p>弱指针到共享指针的转化可以用.lock()来表示</p>

<p>例如</p>

<pre>
<code class="language-cpp">shared_ptr&lt;Girl&gt; sp_girl;
sp_girl = wpGirl_1.lock();

// 使用完之后，再将共享指针置NULL即可
sp_girl = NULL;
</code></pre>

<p>上面share_ptr发生的问题的另一种解决办法</p>

<pre>
<code class="language-cpp">#include &lt;iostream&gt;
#include &lt;string&gt;
#include &lt;memory&gt;

using namespace std;

class Girl;

class Boy {
public:
	Boy() {
		cout &lt;&lt; "Boy 构造函数" &lt;&lt; endl;
	}

	~Boy() {
		cout &lt;&lt; "~Boy 析构函数" &lt;&lt; endl;
	}

	void setGirlFriend(shared_ptr&lt;Girl&gt; _girlFriend) {
		this-&gt;girlFriend = _girlFriend;


		// 在必要的使用可以转换成共享指针
		shared_ptr&lt;Girl&gt; sp_girl;
		sp_girl = this-&gt;girlFriend.lock();

		cout &lt;&lt; sp_girl.use_count() &lt;&lt; endl;
		// 使用完之后，再将共享指针置NULL即可
		sp_girl = NULL;
	}

private:
	weak_ptr&lt;Girl&gt; girlFriend;
};

class Girl {
public:
	Girl() {
		cout &lt;&lt; "Girl 构造函数" &lt;&lt; endl;
	}

	~Girl() {
		cout &lt;&lt; "~Girl 析构函数" &lt;&lt; endl;
	}

	void setBoyFriend(shared_ptr&lt;Boy&gt; _boyFriend) {
		this-&gt;boyFriend = _boyFriend;
	}

private:
	shared_ptr&lt;Boy&gt; boyFriend;
};


void useTrap() {
	shared_ptr&lt;Boy&gt; spBoy(new Boy());
	shared_ptr&lt;Girl&gt; spGirl(new Girl());

	spBoy-&gt;setGirlFriend(spGirl);
	spGirl-&gt;setBoyFriend(spBoy);
}


int main(void) {
	useTrap();

	system("pause");
	return 0;
}
</code></pre>

<p>再次感谢大佬的代码</p>

<p>在这一串代码中主要变的就是各两个类中的对方函数的指针变为了弱指针（在需要的时候用.lock()给变回共享指针，使用完后置空）</p>

<p>这样就避免了双方都没有权限去析构对方类</p>
