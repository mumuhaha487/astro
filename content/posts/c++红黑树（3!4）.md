<h1 id="%E8%A7%A3%E5%86%B3%E5%8A%9E%E6%B3%95">解决办法</h1>

<p>这里要把节点进行右旋</p>

<p>在这里可能听起来会比较难以理解</p>

<h2 id="%E5%8F%B3%E6%97%8B">右旋</h2>

<p>把<span style="background-color:#ff9900;">曾祖父的左孩子指针从祖父那里断开</span>（同时也断开祖父的父亲指针）</p>

<p>然后<span style="background-color:#ff9900;">曾祖父的左孩子指针指向父亲节点</span></p>

<p>同时把<span style="background-color:#ff9900;">父亲节点得到右指针指向祖父节点</span>，<span style="background-color:#ff9900;">如果父亲节点有右孩子节点需要把他提取出来放到原曾祖父的左孩子</span>（同时连接祖父的父亲指针，后面都记得变，不说了）</p>

<p>就完成了右旋的操作</p>

<h1 id="%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9">注意事项</h1>

<p><span style="background-color:#4da8ee;">在每次平衡性调整时，需要注意新节点的颜色最好不要变，因为它可能会是一个整体</span></p>

<p>比如这个 </p>

<p><img alt="" height="253" src="/image/b600a0fa6313c9b547d53719c36e3bb6.png" width="262" /></p>

<p></p>

<p>这里新节点的颜色被整体看为红色</p>

<p>如果后续新节点要变化颜色，这个整体就要变化为黑色（也就是30这个节点变为黑色），一般情况下要篮圈内进行平衡性调整，这是复杂化且不合理的。</p>

<p><span style="color:#fe2c24;">注意——可以改变，只需要将所有颜色互换就行了！！</span></p>

<h1 id="%E6%80%BB%E4%BB%A3%E7%A0%81">总代码</h1>

<p>附上现在更新的总代码</p>

<pre>
<code class="language-cpp">#include &lt;iostream&gt;
using namespace std;
//定义一个颜色
enum Colour
{
	RED,
	BLACK,
};
//定义一个模版T
template&lt;typename T&gt;
//一个节点的结构体
struct RBNode
{
	RBNode* lchild,
		* rchild,
		* parent;
	T	data;
	//初始化为RED也可以后面定义一个初始化函数
	Colour colour=RED;
};
//再定义一个模版T（template只能联系到下面一句语句）
template &lt;typename T&gt;
class RBTree//树
{
public:
	RBTree()
	{
		root = nullptr;
	}
	~RBTree()
	{
		ReleaseNode(root);
	}
	//插入元素
	void InsNode(const T&amp; e)
	{
		InsNode(root, e);
	}
	void InsNode(RBNode&lt;T&gt;*&amp; tnode, const T&amp; e)
	{
		RBNode&lt;T&gt;* point = tnode;
		RBNode&lt;T&gt;* parent = nullptr;
		//深入到叶子节点准备插入新数据
		while (point-&gt;data==nullptr)
		{
			if (e == point-&gt;data)
			{
				printf("该数据已经存在");
				return;
			}
			parent = point;
			if (e &gt;= point)
				point = point-&gt;rchild;
			else
				point = point-&gt;lchild;

		}
		//准备插入数据
		point = new RBNode&lt;T&gt;;
		point-&gt;data = e;
		point-&gt;lchild = nullptr;
		point-&gt;rchild = nullptr;
		point-&gt;parent = nullptr;
		point-&gt;colour = RED;
		
		if (parent == nullptr)
		{
			//插入的是根节点
			point-&gt;colour = BLACK;
			tnode = point;
		}
		//不是根节点
		if (e &gt; parent-&gt;data)
			parent-&gt;rchild = point; 
		else
			parent-&gt;lchild = point;

		point-&gt;parent = parent;
		if (parent-&gt;colour == BLACK)
		{
			count &lt;&lt; e &lt;&lt; "插入完成" &lt;&lt; endl;
			return;
		}
		//接下来就是插入地方的父亲节点是红色的，且深度至少为3（因为第二层父亲节点颜色一定为黑色
		RBNode&lt;T&gt;* uncle = nullptr;
		RBNode&lt;T&gt;* grandpa = nullptr;
		//开始整个平衡性调整
		while (true)
		{
			uncle = (parent-&gt;parent != nullptr) ? (getuncle(parent) :nullptr);
			grandpa = point-&gt;parent-&gt;parent;
			if grandpa == nullptr
				break;
			if (uncle != nullptr &amp;&amp; uncle-&gt;colour == RED)
			{
				parent-&gt;colour = BLACK;
				uncle-&gt;colour = BLACK;
				grandpa-&gt;colour = RED;
				if (grandpa == root)
				{
					grandpa-&gt;colour = BLACK;
					break;
				}
				point = grandpa;
				parent = grandpa-&gt;parent;
				if (parent-&gt;colour == BLACK)
					break;
				continue;
			}


			//（uncle != nullptr &amp;&amp; uncle-&gt;colour == RED）不满足
			int sign = 0;
			RBNode&lt;T&gt;* gff = grandpa-&gt;parent;
			//标记数据sign判断祖父节点与曾祖父节点的关系
			if (gff != nullptr)
			{
				if (gff-&gt;lchild = grandpa)
					sign = 1;
				else
					sign = 2;
			}
			//插入数据的父亲是爷爷的左节点
			if (parent-&gt;parent-&gt;lchild==parent)
			{
				//插入数据是父亲的左节点
				if (parent-&gt;lchild = point)
				{
					RotateRight(grandpa);
				}
				//插入数据是父亲的右节点
				else
				{
					//...
				}
			}
			else
			{
				//...
			}
			if (parent-&gt;colour == BLACK)
				break;
			if (gff == nullptr)
				root = grandpa;
			else if (sign == 1)
				gff-&gt;lchild = grandpa;
			else if (sign == 2)
				gff-&gt;rchild = grandpa;

			break;
		}
		//无论如何根节点颜色为黑色
		root-&gt;colour = BLACK;
	}
private:
	//删除节点，释放内存
	void ReleaseNode(RBNode&lt;T&gt;* pnode)
	{
		if (pnode != nullptr)
		{
			ReleaseNode(pnode-&gt;lchild);
			ReleaseNode(pnode-&gt;rchild);
		}
		delete pnode;
	}

	//获取叔叔节点
	RBNode&lt;T&gt;* getuncle(RBNode&lt;T&gt;* p)
	{
		if (p-&gt;parent-&gt;lchild == p)
			return p-&gt;parent-&gt;rchild;
		else
			return p-&gt;parent-&gt;rchild;
	}

	//右旋节点
	void RotateRight(RBNode&lt;T&gt;*&amp; pointer)
	{
