<h1 id="%E9%A2%98%E7%9B%AE">题目</h1>

<blockquote>
<p>给定一个三角形 <code>triangle</code> ，找出自顶向下的最小路径和。</p>

<p>每一步只能移动到下一行中相邻的结点上。<strong>相邻的结点 </strong>在这里指的是 <strong>下标</strong> 与 <strong>上一层结点下标</strong> 相同或者等于 <strong>上一层结点下标 + 1</strong> 的两个结点。也就是说，如果正位于当前行的下标 <code>i</code> ，那么下一步可以移动到下一行的下标 <code>i</code> 或 <code>i + 1</code> 。</p>
</blockquote>

<h1 id="%E4%BE%8B%E5%AD%90">例子</h1>

<h2 id="%E7%A4%BA%E4%BE%8B%201%EF%BC%9A"><strong>示例 1：</strong></h2>

<pre>
<strong>输入：</strong>triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
<strong>输出：</strong>11
<strong>解释：</strong>如下面简图所示：
   <strong>2</strong>
  <strong>3</strong> 4
 6 <strong>5</strong> 7
4 <strong>1</strong> 8 3
自顶向下的最小路径和为 11（即，2 + 3 + 5 + 1 = 11）。
</pre>

<h2 id="%E7%A4%BA%E4%BE%8B%202%EF%BC%9A"><strong>示例 2：</strong></h2>

<pre>
<strong>输入：</strong>triangle = [[-10]]
<strong>输出：</strong>-10

</pre>

<h1 id="%E5%89%8D%E8%A8%80">前言</h1>

<p>本题是动态规划的一道经典题目，最早出现在1994年的ioi比赛中</p>

<p>经过了20多年的时间，如今已经变成了动态规划的入门必做题</p>

<h1 id="%E6%80%9D%E8%B7%AF">思路</h1>

<p>我们可以以下面的图来举例子</p>

<p>设置数据为一个二维数组（或者是一个容器）</p>

<p>放入[2],[3,4],[6,5,7],[4,1,8,3]四组数据</p>

<p><img alt="" height="104" src="/image/2cf0f89953798b3ab8f1f678583ac9fa.png" width="124" /></p>

<p>我们可以很简单的看出来——最短路径是2，3，5，1</p>

<p>如果把走到响应的点所得到的和（也就是所求值）定义为一个二维数组的话</p>

<p>我们可以得到一个4*4的二维数组（当然其中有一些是用不到了）</p>

<p>那可以把题目转化为求最底下行数组的值，并且比较大小得出最小值</p>

<p>我可以知晓除去第一列的值，其中随机一列的值只取决上一列与其相邻的值，因此我们可以设置递归函数，第a[i][j]的值只取决与原来数组本身的值加上a[i-1][j]与a[i-1][j-1]的最小值。</p>

<p>从底下迭代是一种方法</p>

<p><img alt="" height="104" src="/image/6990976846789c6c24de7fcb792dd088.png" width="124" /></p>

<p>但是他会有一个问题，他会重复大量计算相同的数字</p>

<p>比如上面的例子：</p>

<p>第三行第一列以及第二列都需要知道第二行第一列的数字，所以第二行第一列的值会计算两遍</p>

<h1 id="%E6%80%9D%E6%83%B3">思想</h1>

<p>所以结果就是我从上向下迭代</p>

<p>下一行的数字只会取上一行的值，然而上一行的值都是计算好的</p>

<p>不需要重新计算也不存在重复以及浪费时间</p>

<p><img alt="" height="641" src="/image/c118e92ff467ebdcb1cd954c2f6b8833.png" width="721" /></p>

<p>有些相当于广度优先了</p>

<p>那么思想有了</p>

<p>就是代码实现了</p>

<h1 id="%E4%BB%A3%E7%A0%81">代码</h1>

<h2 id="%E8%B0%83%E7%94%A8%E7%9A%84%E5%87%BD%E6%95%B0">调用的函数</h2>

<pre>
<code class="language-cpp">int minimumTotal(vector&lt;vector&lt;int&gt;&gt;&amp; triangle) {
    int length_1 = triangle.size();
    int length_2 = triangle[length_1-1].size();
    vector &lt;vector&lt;int&gt;&gt; n(length_1, vector&lt;int&gt;(length_1, 0));
    for (int i = 0; i &lt;= length_1 - 1; i++)
    {
        if (i == 0)
        {
            n[0][0] = triangle[0][0];
            continue;
        }
        for (int j = 0; j &lt;= i; j++)
        {
            if (j == 0)
            {
                n[i][0] = n[i - 1][0] + triangle[i][0];
                continue;
            }
            if (j == i)
            {
                n[i][i] = n[i - 1][i - 1] + triangle[i][i];
                continue;
            }
            n[i][j] = min(n[i - 1][j - 1] + triangle[i][j], n[i - 1][j] + triangle[i][j]);
        }
    }
    int min = n[length_1 - 1][0];
    for (int i = 0; i &lt;= length_2 - 1; i++)
        if (n[length_1 - 1][i] &lt; min)
            min = n[length_1 - 1][i];
    return min;
}</code></pre>

<p>思想就是上面讲到的思想</p>

<p>需要注意的是第一行以及第一列与最后一列要单独考虑</p>
