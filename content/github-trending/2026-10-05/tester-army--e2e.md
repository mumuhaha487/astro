e2e 是以 TypeScript 提供的端到端测试框架，面向 Web 与移动应用，可用自然语言驱动应用操作，并结合定位器和断言验证测试结果。

## 项目做什么

项目旨在编写并运行 Web 和移动应用的端到端测试。测试可通过自然语言描述目标，让代理执行应用操作，再用框架提供的定位器和断言检查结果；仓库还提供 SDK、测试运行器和命令行工具。

## 与同类方案相比

README 展示了自然语言操作与常规断言可以出现在同一测试中；通过后续断言验证的代理步骤会记录操作，并在应用未变化时于下一次运行中重放，减少这些步骤的模型调用。项目也支持无需代理步骤的测试，并允许用户选择订阅、API 密钥或本地模型。

## 设计与创新

项目将自然语言代理操作、断言和操作记录重放组合在端到端测试流程中；README 也列出 Web、移动端及决策模型等配套包。不过，仅凭仓库简介和 README 无法验证这些设计是否具有行业首创性、相较其他方案有何差异，或在实际项目中的效果。

## 适用场景

适用于需要验证 Web 或移动应用用户流程的测试，例如打开账单设置、执行升级操作并检查页面状态。团队也可在持续集成中运行测试；README 提及 GitHub 拉取请求结果报告器，以及托管浏览器、模拟器和仿真器相关组件。

## 谁会受益

对希望在代码测试中表达部分用户目标、同时保留明确断言的团队，该项目提供了一个 TypeScript 框架入口，并通过初始化命令生成配置和示例测试。是否能适配具体应用、模型提供方、运行环境和现有测试流程，还需结合项目文档及实际运行验证。

## 使用前需要注意

项目仍处于迈向 1.0 的开发阶段，README 明确提示 API 和配置可能在次版本间变化。代理步骤需要模型配置，重放行为以应用未变化为条件；此外，README 未提供足以核实的性能数据、稳定性评估或与其他框架的对比结果。CLI 会发送匿名使用数据，用户可按文档选择关闭。
