openGym 是一个可自托管的健身与体重追踪应用，支持制定训练计划、记录训练和观察身体状态。数据保存在用户自己的服务器，也可通过手机独立使用；项目提供容器部署、跨设备同步及从多款健身应用导入数据的功能。

## 项目做什么

项目面向希望规划训练并记录训练、体重与进度的个人用户，尤其适合希望自行管理数据和部署环境的人。它提供每周训练安排、引导式训练、动作与组次记录、进阶规则、肌群状态图，以及历史训练和体重趋势查看；也支持将 FitNotes、Strong、Hevy 等来源的数据导入。

## 与同类方案相比

README 描述的主要便利包括：可用 Docker Compose 自托管，数据文件保存在宿主机目录并可备份；具备离线使用和跨设备同步机制；支持通行密钥登录、训练记录导出及修改历史训练。功能覆盖热身、超级组、有氧、体重训练等场景，并提供 Android 安装包和可添加到主屏幕的 PWA。实际安全性、稳定性和易用程度仍需结合部署与使用情况评估。

## 设计与创新

项目提供肌群训练量、恢复中和长期未训练等视图，并将进阶目标与训练记录结合；同步采用服务器修订号检测并发修改，再由设备合并后重试。另有可选 AI 教练和只读 MCP 服务，但这些功能并非默认启用。README 未提供足以证明其相较其他产品具备独特创新或技术领先性的对比材料，因此创新程度尚无法验证。

## 适用场景

适用于个人在家或健身房安排每周训练、按动作记录重量与次数、追踪体重及个人纪录，也适合从其他记录应用迁移历史数据。拥有服务器的用户可部署网页端并让手机与电脑同步；不希望搭建服务器的用户可考虑独立手机应用。AI 教练要求自行配置模型服务及密钥，MCP 服务则面向希望以本地只读方式查询训练历史的用户。

## 谁会受益

对重视数据由自己保管、需要多设备查看训练记录，或希望把计划、训练执行和进度观察放在同一应用中的用户，项目具备较明确的实用价值。丰富的动作库、可编辑计划、训练导入导出和离线提示能覆盖常见记录流程。不过，自托管用户仍需理解 Docker、域名或 HTTPS 等部署要求；是否适合个人取决于其维护意愿、设备和记录习惯。

## 使用前需要注意

README 所述默认数据存储为 JSON 文件，并非关系型数据库；路线图将数据库存储列为未来版本计划，当前规模下的扩展和并发表现没有给出实测依据。远程使用通行密钥需要 HTTPS 和域名配置，首次启动还会下载约 140 MB 的动作媒体。iPhone 原生安装受平台限制，当前建议使用 PWA 或自行通过 Xcode 构建。项目也未提供可核实的性能基准、用户规模或竞品比较；实际保障与配置安全性仍需用户自行验证。
