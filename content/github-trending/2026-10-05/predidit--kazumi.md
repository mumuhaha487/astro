Kazumi 是使用 Flutter 与 Dart 开发的跨平台番剧采集和在线观看应用，通过用户自定义规则检索内容，并提供播放器、弹幕、下载及实时超分辨率等功能。

## 项目做什么

项目旨在让用户通过自定义采集规则查找和观看番剧。规则使用基于 XPath 的选择器编写，单条规则最多五行，并可导入或分享；应用还整合番剧目录、搜索、时间表、分集播放与多视频源支持。README 列出的功能包括字幕、弹幕、追番列表和观看历史等。

## 与同类方案相比

项目将规则编辑、内容发现和观看功能集中在同一应用中，并支持 Android、Windows、macOS、Linux 和 iOS；README 将 Linux 标注为实验性，将 iOS 标注为需要侧载。功能还涵盖外部播放器、DLNA 投屏、倍速播放、跨设备同步和番剧下载。实际可用性会受到设备、视频源及规则适配情况影响。

## 设计与创新

README 展示的主要设计特点是用自定义规则连接内容检索与播放，并提供规则分享；但现有资料不足以证明这是行业首创或相较其他项目具有技术优势。项目还集成 Anime4K 实时超分辨率、弹幕交互和 SyncPlay 协议的一起看功能，这些是功能组合的描述，不构成未经验证的创新性结论。

## 适用场景

适用于希望自行添加或导入采集规则、按目录或时间表查找番剧，并在一个应用中观看和管理播放记录的用户。用户也可按需使用弹幕、倍速、投屏、下载或外部播放器。若视频源访问受限、规则不匹配或设备不支持相关播放路径，具体体验可能不同。

## 谁会受益

对于愿意维护规则并从多个视频源检索内容的用户，规则编辑与分享能力可用于扩展内容来源；番剧搜索、时间表、追番列表和历史记录可辅助日常浏览。实时超分辨率可作为可选播放处理功能，但 README 提醒其对 GPU 要求较高，启用后可能发生卡顿。

## 使用前需要注意

规则解析对 XPath 的支持并不完整，目前只支持以双斜线开头的选择器；部分内容能检索但未必能播放。README 还指出超分辨率可能增加 GPU 负担，播放会缓存视频并占用内存，部分来源可能有广告或反盗链措施。项目依赖外部视频源与平台服务，资料未能验证其覆盖范围、稳定性或与其他项目的比较优势。
