i-have-adhd 是面向编程助手的输出规范技能，旨在让回答先给行动、步骤清晰并减少铺垫；仓库提供安装指引、规则说明和可编辑的技能文件。

## 项目做什么

项目希望改变编程助手组织回答的方式：优先呈现用户接下来要做的事，将多步任务编号，并减少离题内容、冗长开场和泛泛结尾。README 将其定位为面向大语言模型回复的适配，而非帮助人类安排日常生活的工具，也说明不要求使用者具有 ADHD 诊断。

## 与同类方案相比

README 展示了修改前后的回答示例，能具体说明其期望的表达差异；规则涵盖行动优先、步骤编号、列表长度、错误措辞和明确下一步等方面。项目还提供技能文件路径及自定义流程，使用者可以据此调整规则，而不必只采用默认文本。

## 设计与创新

仓库简介与 README 支持的特点，是把一组面向注意力友好沟通的要求整理成可供编程助手采用的技能规则，并附有示例和调整方式。是否构成相对于其他同类提示或技能的创新，现有材料没有提供比较依据，因而无法验证其独特性或新颖程度。

## 适用场景

可考虑在使用编程助手处理代码修改、测试或排错时启用，以便让回答更快给出操作建议，并把后续步骤写清楚。示例涉及更新令牌验证函数和运行测试；README 没有证明该技能只适用于这些任务，也未说明对所有助手或工作流程均适用。

## 谁会受益

对于偏好短而明确指令、容易被长篇铺垫打断，或希望每轮对话都知道下一步做什么的用户，这套规则可能有参考价值。它还提供了可编辑文件和 Claude 插件相关命令，便于按需调整或安装；实际帮助程度仍取决于助手是否遵循规则及用户偏好。

## 使用前需要注意

README 主要描述期望的回答风格和安装、修改方式，没有给出受支持的助手与版本范围、测试结果、效果评估或规则冲突处理说明，因此实际兼容性和效果尚无法验证。仓库简介标注 Python，但给定材料未说明 Python 代码在技能中的作用；同类项目比较也缺乏依据。
