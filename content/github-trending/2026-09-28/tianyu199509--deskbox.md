DeskBox 是一款免费开源的 Windows 桌面整理工具，以 WinUI 3 组件形式运行。它通过真实文件夹支持的组件管理桌面文件，并集成待办、快速捕获、搜索、天气、音乐等日常工具，同时保留原有文件结构。

## 项目做什么

DeskBox 的核心目标是解决 Windows 桌面上文件图标堆积、难以整理的问题，同时不替代资源管理器或改变用户原有的文件组织方式。它允许用户创建由普通文件夹支持的组件，或直接映射已有文件夹而不移动内容，从而在桌面上以更有序的方式呈现文件。此外，它还集成了待办清单、快速捕获、桌面搜索、天气和媒体控制等日常工具，旨在让用户无需切换多个应用即可完成常见操作。根据 README，这些扩展功能被定位为附加价值而非产品核心承诺。

## 与同类方案相比

根据 README 描述，DeskBox 的主要优势包括：使用 WinUI 3 和 Mica/Acrylic 材质，提供接近原生 Windows 应用的视觉体验；支持 x64 和 ARM64 架构，且安装包为完整 Native AOT 构建，可离线安装；数据本地优先，文件、笔记、任务和布局均保存在本机；支持十二种语言且资源键和格式占位符覆盖一致。此外，文件组件直接映射真实文件夹，不移动或改变文件结构，支持拖放、快捷键、堆叠、分组、胶囊模式等丰富的桌面交互功能。但 README 未提供性能基准或与其他工具的量化对比，因此实际优势尚无法验证。

## 设计与创新

README 中提及的较具特色的设计包括：文件组件直接由普通文件夹支持，并可映射已有文件夹；支持将文件组件合并为组而不改变底层文件夹，成员间可快速切换；桌面整理预览功能允许在移动文件前按类别查看结果，并选择创建文件夹或复用已有组件；胶囊模式可将组件折叠为智能胶囊，支持悬停展开、组合成可移动栏；布局按显示器拓扑分别保存并在热插拔后恢复；云备份到用户自己的 WebDAV 服务器，支持选择性恢复和合并策略。这些功能在同类桌面整理工具中可能具有差异化，但 README 未明确说明其首创性或独特技术原理，因此创新程度尚无法独立验证。

## 适用场景

DeskBox 适用于希望保持桌面整洁但不愿改变文件存储位置的 Windows 10/11 用户。典型场景包括：将散落的桌面文件按项目或类型整理到由真实文件夹支持的组件中；映射已有的下载、文档或工作文件夹到桌面组件以便快速访问；使用待办和快速捕获记录临时任务或灵感；通过桌面搜索弹出窗口快速查找文件、应用或笔记；利用天气和音乐组件减少切换窗口的频率。对于多显示器用户，DeskBox 能针对不同显示器拓扑保存和恢复布局。对于需要备份数据的用户，可通过 WebDAV 将待办、快速捕获和组件样式备份到自有服务器。
