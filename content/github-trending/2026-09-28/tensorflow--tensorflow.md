TensorFlow 是端到端开源机器学习平台，由 Google Brain 团队发起，提供稳定的 Python 和 C++ API 及多语言支持，拥有完整的工具、库和社区生态。

## 项目做什么

TensorFlow 旨在为研究人员和开发者提供一个端到端、开源且面向所有人的机器学习平台。它最初由 Google Brain 团队为机器学习和神经网络研究而开发，但设计上足够通用，可应用于其他领域。其目标是让研究人员能够推动机器学习领域的最新进展，同时让开发者能够轻松构建和部署由机器学习驱动的应用程序。通过提供稳定的 Python 和 C++ API 以及其他语言的兼容 API，TensorFlow 试图降低机器学习的应用门槛，并借助全面的工具、库和社区资源，支持从研究到生产的全流程。
