## 项目做什么

项目旨在收集 macOS 软件并按类别整理，帮助用户发现适合自身需求的应用。README 提供目录导航、应用简介和相关网站或代码仓库链接，还以图标标示部分条目的开源、免费、原生应用及 App Store 信息；项目也欢迎用户按贡献指南提交补充。

## 与同类方案相比

按用途细分的目录覆盖面较广，从文本编辑、开发工具、设计与影音，到安全、窗口管理和包管理等均有分类，降低了从零开始搜索的成本。条目附有简短描述和外链，部分还标注开源、免费或原生属性；README 同时提供中文、日文、韩文版本及相关列表链接。

适用于准备寻找 macOS 应用的个人用户，例如按开发、写作、设计、沟通、影音或系统维护等任务浏览候选工具；也可用于了解某个应用是否有开源仓库、官网或 App Store 页面。希望扩充目录的贡献者可参考 README 中的贡献指南提交软件条目或建议。
