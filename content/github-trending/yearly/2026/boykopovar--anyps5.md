AnyPS5 是一款以 C++ 开发的 PS5 可执行文件移植工具，目标是在 Linux 和 Windows 上运行程序，采用可执行文件重链接与系统 PRX 库实现，而非模拟或独立运行时进程。

## 项目定位与要解决的问题

AnyPS5 面向 PS5 可执行文件在 Linux、Windows 上的兼容与运行问题，项目简介将其定位为自动移植工具，而不是传统意义上启动完整主机环境的模拟器。它的路线是把可执行文件转换为目标系统的原生格式，并提供适合动态链接的系统 PRX 库实现。由此，项目所处理的不只是二进制格式转换，也包括程序对系统库接口的依赖。README 将互操作性、研究、保存与兼容性列为项目用途；这说明其目标侧重于让已有程序在不同平台上运行，但不代表所有 PS5 程序或系统功能均已支持。具体覆盖程度应结合项目的已验证游戏列表和状态页面判断。

## 核心能力

项目的核心由两类工作构成：其一是 relinker，负责将可执行文件转换为目标系统的原生格式；其二是 core/libs/prx 中的系统 PRX 库实现，供程序进行动态链接。README 明确说明方案不采用模拟，也不启动独立运行时进程，因此其实现重心落在可执行文件转换和被依赖接口的适配上。项目还包含着色器重编译器；README 称其能够生成 SPIR-V，并可在启用 ANYPS5_ENABLE_SPIRV_TOOLS 构建选项时通过 Spirv-Tools 验证。系统库进度指标统计的是项目目前已知并声明的函数比例，而不是全部 PS5 系统函数的覆盖率；随着新增函数声明，统计总量本身也会变化，因此不能将该指标解读为完整兼容度。

## 技术结构与实现思路

从 README 能确认的架构边界包括可执行文件转换、动态链接库实现和着色器重编译三个部分：重链接器处理目标格式转换，PRX 实现承接程序对系统库的依赖，着色器重编译器则负责生成 SPIR-V。项目将这些代码分别指向 core/relinker、core/libs/prx 和 core/shader/recompiler/Recompiler.cpp。README 没有提供模块间调用顺序、内部数据结构或具体接口细节，因此不能据此补写更细的执行机制。错误处理方面，未支持或意外状态会抛出 std::runtime_error，错误信息打印到标准错误流，随后进程终止；这体现了当前遇到未知情况时采取明确失败而非继续运行的处理方式。用户输入支持 SDL 映射的手柄，也可通过 anyps5-input.ini 配置键盘和鼠标控制。
