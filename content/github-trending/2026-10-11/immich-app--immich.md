Immich 是一套自托管的照片与视频管理方案，提供移动端和网页端访问，并涵盖备份、整理、搜索、共享及管理等功能。

## 项目做什么

项目旨在让用户自行部署照片和视频管理服务，并通过移动应用与网页端上传、浏览和组织媒体。README 列出的功能包括自动备份、相册、元数据查看、搜索、用户管理和分享；具体部署条件需参考项目文档。

## 与同类方案相比

README 展示了较广的功能覆盖：移动端和网页端均支持上传浏览、相册、公共分享、地图和元数据查看；还列出人脸识别与聚类、多用户、离线支持等能力。部分功能依客户端而异，例如标签仅列为网页端支持，管理功能也未列为移动端支持。

## 设计与创新

现有简介和 README 能证明项目包含对象、人脸、CLIP 等搜索方式，以及 Live Photo、Motion Photo、360 度图片等相关支持，但没有提供足以判断技术原创性或相对创新程度的说明，也没有给出与其他方案的系统比较，因此创新性尚无法验证。

## 适用场景

适合希望在自有环境中集中管理个人或多人照片、视频的用户，也可用于移动设备媒体自动备份、按相册选择备份、浏览与分享家庭影像。是否适合具体部署环境，还需结合文档核实硬件、存储、网络及安装要求。

## 谁会受益

若用户需要自托管媒体库，项目列出的备份、相册、收藏、归档、地图、搜索和共享功能可支持从导入到查找、浏览的日常流程。多用户与网页管理也可能适用于多人共用场景；实际效果和维护成本不能仅凭 README 确定。
