这是一个面向 Claude Code 的轻量级行为指南项目，以单个 CLAUDE.md 为核心，归纳四项原则，旨在减少编码任务中的误解、过度设计和无关改动。

## 项目做什么

项目将 README 所述的大语言模型编码常见问题转化为可供 Claude Code 遵循的指引，重点要求先澄清假设与歧义、优先采用简单方案、限制改动范围，并用可验证的成功条件推进任务。它提供的是行为约束与工作方法建议，不是代码生成引擎或自动化测试工具。

## 与同类方案相比

指南结构清楚，将原则拆解为具体做法，例如遇到不确定时提问、避免未经请求的抽象、保留无关代码，并为任务设定验证标准。README 还说明可通过插件或项目级 CLAUDE.md 使用，并提及 Cursor 规则文件，便于按不同项目环境采用；实际效果仍取决于模型和使用者。

## 设计与创新

README 将思考前置、简单优先、手术式修改和目标驱动执行整合为一套面向编码代理的提示规范，并强调把命令式任务转成可验证目标。现有材料只能说明其组织方式与设计侧重点，未提供实验数据或系统比较，因此无法验证它相较其他提示指南是否具有独特创新或更好效果。

## 适用场景

适用于希望 Claude Code 在维护现有代码、修复缺陷、添加验证或进行重构时减少猜测和非必要修改的开发者。多步骤任务可依据指南先列计划与检查点；需求存在歧义时可用其规则促使代理先询问。对简单改动，README 也提醒无需机械套用完整流程。

## 谁会受益

对于需要统一代理协作习惯的个人或团队，这份指南提供了可直接纳入项目指令文件的规则清单，也给出了插件安装及项目级添加方式。它有助于明确期望的改动边界与验证方式，但文档本身不能保证模型一定遵守要求，也不能替代代码审查、测试或项目自身的技术规范。

## 使用前需要注意

项目核心是自然语言指令，实际遵循程度可能随模型、上下文和任务变化；README 未提供受控评测、量化结果或不同模型的适用性证据。谨慎、少改动等取向也可能不适合所有任务，具体仍需结合项目要求判断。关于其与其他方案的效果差异及独特优势，现有资料不足，尚无法验证。
