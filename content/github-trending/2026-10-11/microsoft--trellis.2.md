TRELLIS.2 是一个用于图像生成三维资产的 Python 项目，提供预训练的 4B 参数模型、O-Voxel 表示、推理示例和训练代码，可生成带 PBR 属性的 3D 结果。

## 项目做什么

项目面向从单张图像生成三维资产，也提供针对既有形状生成 PBR 纹理的流程。仓库包含模型推理、网页演示、资产表示转换及训练相关脚本；训练数据需先整理并转换为 O-Voxel 或相应潜变量格式。

## 与同类方案相比

README 描述其 O-Voxel 稀疏体素表示可处理开放表面、非流形几何和内部封闭结构，并建模基础颜色、粗糙度、金属度及透明度等属性。仓库还提供 GLB 导出示例和训练代码。文档列出的生成时间是在 H100 上测得，不能据此推断其他硬件表现。

## 设计与创新

项目将 O-Voxel 称为“field-free”结构，并以稀疏 3D VAE 将资产编码为紧凑潜空间，作为形状与材质生成的表示基础。README 声称该方案可避免某些传统等值面表示的拓扑限制，但没有给出足以独立核实的比较实验细节，因此相对既有方法的创新程度尚无法验证。

## 适用场景

适用情形包括根据参考图像制作可继续编辑或渲染的 3D 初始资产，为现有三维形状生成 PBR 纹理，以及研究人员基于所提供训练代码训练或微调模型。示例展示将结果导出为 GLB；若需启用透明效果，文档说明还要在目标软件中配置材质通道。

## 谁会受益

对希望尝试图像到三维生成、研究结构化潜变量或搭建自有训练流程的开发者，仓库提供了预训练权重入口、推理与演示示例、训练配置及数据准备指引。其资产转换和 GLB 导出流程也可作为工作流参考，但实际能否融入具体应用仍需结合格式、质量和部署要求测试。

## 使用前需要注意

文档说明代码目前仅在 Linux 上测试，要求 NVIDIA GPU 至少 24GB 显存，并依赖 CUDA 及多个专用组件，安装与数据预处理存在门槛。生成耗时数据仅对应 H100；输出透明度默认未启用。README 未提供足以判断多硬件泛化、生成质量边界或与其他系统对比结果的信息，相关结论尚无法验证。
