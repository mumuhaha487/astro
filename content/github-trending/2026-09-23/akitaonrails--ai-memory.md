ai-memory 是一个用 Rust 实现的开源项目，为 AI 编码代理提供长期记忆。它通过生命周期钩子自动捕获工作过程，将记忆以 git 支持的 Markdown 维基形式存储，并支持跨代理、跨机器和团队共享。默认零 LLM 调用，可自托管服务器。

## 项目做什么

该项目旨在解决 AI 编码代理的长期记忆和跨代理交接问题。它通过生命周期钩子自动捕获提示和工具调用，在会话结束时将观察结果整合为 Markdown 页面，形成项目维基。下一个会话无论使用哪个代理，都能获得有界简报并搜索全部记忆，实现无缝交接。同时支持多用户团队共享，记忆存储在自托管服务器上，实现跨机器同步。

## 与同类方案相比

主要优势在于记忆以 git 支持的纯 Markdown 文件为真实来源，数据库仅作为可重建的索引，避免了向量库的维护负担。默认路径零 LLM 调用，无需 API 密钥即可完成捕获、搜索和交接。支持超过二十种代理工具，提供跨代理、跨机器的共享记忆，并内置多用户认证、归属和审计日志。记忆可手动编辑，兼容 grep、Obsidian 等工具，无供应商锁定。

## 设计与创新

其创新点包括：将交接协议化为类型化、一次性声明的显式过程；默认零 LLM 的捕获与整合机制；基于访问权重的记忆衰减和保留策略，可逆且不硬删除；可选的后台“做梦”整合过程，将冷记忆重写为连贯页面，但默认关闭且不删除源内容。此外，项目将文件优先的 Markdown 维基与自动生命周期捕获结合，提供了实体、链接和可选向量的融合检索。

## 适用场景

适用于个人开发者在不同机器间切换编码任务，或在不同 AI 代理之间交接工作。团队协作中，成员可共享同一服务器，使一个会话学到的知识被所有人的代理检索。长期项目中，自动捕获和记忆衰减机制有助于保留关键决策和失败经验。对于隐私敏感环境，可完全离线运行，无需外部 API 密钥。也适合需要审计追踪和用户归属的合规场景。

## 谁会受益

该工具能显著减少重复解释项目上下文的需要，提升开发效率。通过自动捕获工作过程，避免了手动记录记忆的负担。跨代理和跨机器的共享特性，使得开发者可以在不同工具和地点之间无缝继续工作。团队共享功能促进了知识传递，减少了信息孤岛。零 LLM 默认模式降低了使用成本和隐私风险，而可选的 LLM 增强提供了灵活性。对于依赖多种 AI 编码代理的开发者，这是一个实用的基础设施。

## 使用前需要注意

项目对原生 Windows 的支持仍为实验性，需通过 WSL2 获得较好体验。部分代理集成仅为 MCP-only 或仅支持钩子，功能可能受限。默认无认证，需自行配置安全措施以暴露于局域网。零 LLM 模式下，搜索可能依赖全文检索，语义搜索需额外配置嵌入提供者。记忆衰减和压缩等高级功能默认关闭，需手动启用。README 中未提供性能基准数据，实际扩展性尚无法验证。与竞品的比较优势多基于项目自述，缺乏独立验证。
