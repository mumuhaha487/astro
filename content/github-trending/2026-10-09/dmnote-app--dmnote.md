DM Note 是一款面向 DJMAX RESPECT V、也可用于其他游戏的可定制按键可视化工具，适用于 Windows 10/11 和 macOS。它提供实时输入显示、按键布局与外观调整，并可作为桌面覆盖层或 OBS 浏览器源使用。

## 项目做什么

项目的主要用途是在游戏过程中捕捉并展示按键输入，便于玩家在直播或录制的视频中呈现操作过程。README 说明它最初为 DJMAX RESPECT V 制作，但也支持其他游戏；输入检测在 Windows 使用 Raw Input API，在 macOS 使用全局输入事件。它不是只面向某一游戏的固定按键布局工具，用户可配置键位和显示方式。

## 与同类方案相比

可定制范围覆盖按键映射、网格布局、逐键图片、CSS、插件和预设，并提供实时可视化、按键计数、KPS 统计与图表及按键音。覆盖层支持置顶、位置固定和缩放锚点，也可通过 OBS 浏览器源使用。README 还说明支持五种语言、快捷键和自动更新；这些是功能清单所述，实际效果与资源占用未提供独立验证数据。

## 适用场景

适合 DJMAX RESPECT V 玩家在游玩时显示按键输入，也可用于其他游戏的直播、录屏和操作演示。用户可以在本机显示覆盖层，或通过 OBS 浏览器源将画面接入制作流程；若游戏覆盖置顶窗口，README 建议改用无边框窗口模式。双电脑直播场景下，可在游戏电脑运行程序并由采集电脑的 OBS 浏览器源连接。

## 谁会受益

对于希望让观众看见键盘操作、展示节奏游戏输入或制作带操作反馈的视频的用户，DM Note 提供从输入映射到画面呈现的一套配置功能。键计数和 KPS 图表可用于呈现输入统计，逐键图片、CSS 与预设则便于调整视觉风格。项目允许将其用于直播或游戏视频制作；具体是否符合个人平台、插件及素材的使用要求仍需自行确认。
