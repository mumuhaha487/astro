video-shotcraft 是面向 Claude Code 与 Codex 的 Remotion 视频制作技能，提供分镜配方、动画示例、产品宣传片模板及制作流程资料。

## 项目做什么

项目旨在让 AI 编程代理辅助制作产品宣传片、发布视频和功能演示。用户提供产品信息后，代理可按技能流程规划故事板、实现动画并配置音效；项目也提供可运行的 Remotion 模板，供用户替换产品截图、文案和品牌内容。

## 与同类方案相比

仓库将分镜配方、对应的 Remotion 示例、完整视频模板和制作方法集中提供，配方包含用途、节奏、时长建议、参数及注意事项。README 还列出音效资源、素材采集脚本、视觉检查指引和可在浏览器使用的工作台，有助于把创意参考连接到实现与后期调整。

## 设计与创新

README 所述特色包括按配方卡组织动画参考、在浏览器工作台中调整镜头及字幕等内容，以及导出可继续编辑的 JianYing 草稿；这些是项目描述的功能组合。仅凭简介和 README，无法验证其相对于其他工具的创新程度、独特性或实际效果，也无法确认所有列出的能力在不同环境均可用。

## 适用场景

较适合制作网页或桌面产品的宣传片、功能演示、品牌影片和发布视频，也可从单张配方卡挑选某种镜头动效用于其他项目。README 给出的模板规格为 36.2 秒、1920×1080、30fps、10 个镜头；实际项目仍需替换演示截图和文案，并检查是否含有需匿名化的数据。

## 谁会受益

对于使用 Claude Code 或 Codex、并愿意采用 Remotion 工作流的创作者，项目可提供可参考的镜头实现、预览、模板及制作检查资料，降低从零组织视频结构和动画代码的准备工作。若交付后还需修改，README 描述的工作台和 JianYing 草稿导出可作为后续编辑路径，但适用性应结合本地环境验证。

## 使用前需要注意

目前提供的信息不能证明成片质量、制作耗时、渲染性能或用户实际效果，也不足以判断它相对其他视频制作方案的优劣。它主要面向产品类视频，使用者仍需准备准确的产品素材、判断视觉方向并检查最终成片。README 提及音频素材许可各有条款且 Remotion 自有许可要求，因此不能据此将整个仓库概括为单一许可证或断言所有场景均可免费商用。
