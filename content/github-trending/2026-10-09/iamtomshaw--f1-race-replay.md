这是一个基于 Python、FastF1 与 Arcade 的 F1 比赛回放和数据可视化工具，支持赛道位置动画、遥测查看及交互式回放控制。

## 项目做什么

项目用于读取和处理 F1 赛事数据，并将比赛过程呈现为可交互的图形回放。用户可以按年份和分站选择赛事，也可查看车手位置、名次、轮胎信息及部分遥测数据；项目还提供排位赛回放入口，但文档说明该功能仍在完善中。

## 与同类方案相比

README 所列的实用特点包括图形界面与命令行两种选择、暂停和调速等回放控制，以及车手选择后查看速度、挡位和 DRS 状态。首次处理过的赛事数据可缓存供后续加载；安全车部署时间依据赛道状态数据，位置则通过领跑者位置进行模拟，并非实际 GPS 轨迹。

## 设计与创新

项目包含安全车的部署、赛道行驶和返回等动画阶段，并将模拟坐标及阶段信息纳入逐帧数据；README 还介绍了遥测分析窗口的扩展方式。不过，现有材料只能说明这些实现及接口设计，未提供与其他工具的对比或独立评估，因此无法据此确认其创新性或相对优势。

## 适用场景

适合希望以可视化方式回顾某场 F1 比赛、观察车手相对位置变化或查看指定车手部分遥测信息的用户，也可用于赛事数据探索和 Python 图形应用学习。已知赛事可通过命令参数选择；若活动包含冲刺赛或排位赛，可使用相应选项，但排位赛功能仍处于完善阶段。

## 谁会受益

对个人观赛复盘和初步数据观察而言，项目把遥测处理结果、赛道动画、排行榜和常用播放控制集中在同一应用中，减少了只通过原始数据查看比赛的门槛。开发者也可依据 README 提到的窗口基类尝试制作自定义遥测视图；具体可扩展范围仍应以代码和相关文档为准。

## 使用前需要注意

首次加载赛事需要下载和处理遥测数据，耗时可能较长，且应用依赖 Python 3.11 以上、FastF1、Arcade 和 NumPy。README 明确指出排行榜在比赛初段、进站期间及终点附近可能不准确；安全车位置是模拟值，旧缓存可能缺少相关数据，排位赛支持也仍在完善，部分环境还可能遇到 OpenGL 兼容问题。
