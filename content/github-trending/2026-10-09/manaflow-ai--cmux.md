cmux 是面向 macOS 的 Ghostty 系终端应用，采用 Swift 和 AppKit 构建，并使用 libghostty 渲染终端。它把工作区与分屏管理、代理通知、内置浏览器和可编程接口整合在一个原生应用中。

## 项目做什么

项目旨在帮助开发者同时管理多个终端与 AI 编程代理会话。侧边栏展示工作区的目录、Git 分支、关联 PR、监听端口及最新通知；通知面板和未读跳转则用于定位需要人工处理的代理会话。它也提供浏览器和 CLI，支持将相关开发操作纳入同一工作环境。

## 与同类方案相比

README 所述的具体便利包括纵向与横向分屏、工作区通知提示、CLI 与 socket API，以及可从终端控制工作区、面板和浏览器。应用可读取现有 Ghostty 配置中的主题、字体与颜色，并提供 SSH 工作区和浏览器导入等功能。会话恢复覆盖应用保存的布局、工作目录、尽力恢复的终端滚屏及浏览器历史，但不等于保存任意进程状态。

## 设计与创新

项目将 Ghostty 终端、代理通知、工作区元数据与可脚本化的内置浏览器组合在原生 macOS 应用中；浏览器 API 支持读取无障碍树、定位元素和执行交互。README 描述了这些设计及其用法，但没有提供足够证据证明其技术首创性或相对其他产品的创新优势，因此创新程度尚无法独立验证。

## 适用场景

适用于在 macOS 上并行运行 Claude Code、Codex 等代理或多个终端任务的开发者，可用侧边栏查看各工作区状态，并通过通知定位等待输入的会话。需要在终端旁查看本地开发页面、自动化浏览器交互、通过 SSH 访问远程机器，或用 CLI 批量创建工作区和分屏时，也可以考虑使用。

## 谁会受益

当工作流包含多个代理会话、终端面板和开发浏览器时，集中呈现通知与工作区信息有助于减少来回查找。CLI、socket API、自定义命令和代理 hooks 可用于构建个人自动化流程；Ghostty 配置兼容则便于沿用部分现有外观设置。实际收益取决于用户是否采用这些工作方式，README 未提供量化评测。

## 使用前需要注意

该项目是 macOS 应用，README 未说明其他操作系统支持。它基于 Ghostty/libghostty，但不应据此推断具备 Ghostty 的全部行为或兼容性。会话快照不保存任意进程的实时状态，终端滚屏仅尽力恢复；部分代理恢复依赖已配置的 hooks，跨安装导入也会受到信任规则限制。性能、与其他工具的比较优势及项目长期维护状况，均无法仅凭所给材料验证。
