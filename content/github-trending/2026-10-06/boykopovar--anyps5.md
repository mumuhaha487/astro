AnyPS5 是一个以 C++ 编写的工具，旨在将 PS5 可执行文件移植到 Linux 和 Windows，包含可执行文件重链接器及用于动态链接的系统 PRX 库实现。

## 项目做什么

项目目标是让部分 PS5 可执行文件能够在 Linux 或 Windows 上运行。README 描述的实现包括把可执行文件转换为目标系统原生格式的重链接器，以及适用于动态链接的系统 PRX 库实现；项目称其方案不使用模拟器或独立运行时进程。

## 与同类方案相比

README 提供了已验证游戏列表、兼容性信息、构建与使用文档，并说明支持 SDL 映射的手柄，包括摇杆和扳机；键盘鼠标映射可通过配置文件设置。这些信息有助于用户了解已测试范围和输入配置方式，但不能据此推断所有游戏或设备均可用。

## 设计与创新

项目介绍了重链接器与系统 PRX 库实现的组合，并称其无需模拟器或独立运行时进程；此外，着色器重编译器可以生成 SPIR-V，启用相关构建选项时可通过 Spirv-Tools 验证。README 未提供与其他方案的对照或充分技术细节，因此其创新程度及相对优势尚无法验证。

## 适用场景

根据 README，项目面向希望在 Linux 或 Windows 上尝试运行 PS5 可执行文件的用户，也提及互操作性、研究、保存与兼容性用途。实际适用范围应以已验证游戏清单、已实现的系统库函数及已知问题为准，不能据此认为任意 PS5 软件都能运行。

## 谁会受益

对于研究兼容性实现或评估特定游戏能否在目标系统运行的用户，项目提供了游戏验证清单、库函数状态信息、输入映射说明以及构建和使用文档。README 还报告 Dreaming Sarah 在指定硬件配置上稳定运行于 60 fps，但这是单一案例，不能推广为普遍性能结论。

## 使用前需要注意

README 指出系统库进度统计仅针对项目已声明的函数，并非全部 PS5 系统函数；遇到不支持或异常状态时会抛出 std::runtime_error、将信息输出到标准错误并终止进程。实际兼容性与已实现功能范围有限，具体覆盖率、更多硬件表现及与其他方案的比较，依据现有信息尚无法验证。
