MiroFish 是一个基于多智能体技术的开源群体智能预测引擎，可从新闻、政策或金融信号中提取种子信息，构建高保真数字世界，让数千个具备独立人格与记忆的智能体自由互动演化，支持从上帝视角注入变量以推演未来轨迹，并生成预测报告。

## 项目做什么

该项目旨在构建一个通用群体智能预测系统，通过多智能体模拟突破传统预测方法的局限。其核心用途是让用户上传种子材料（如数据分析报告或小说故事），用自然语言描述预测需求，系统便自动构建数字世界并返回详细预测报告。从宏观层面看，它可作为决策者的零风险预演实验室，用于测试政策或公关效果；从微观层面看，它是个体用户的创意沙盒，可推演小说结局或探索想象场景，覆盖严肃预测与趣味模拟。

## 与同类方案相比

项目提供源码和 Docker 两种部署方式，支持 OpenAI SDK 格式的任意 LLM API，并集成 Zep Cloud 管理记忆，降低了使用门槛。工作流涵盖图谱构建、环境设置、双平台并行模拟和报告生成，支持与任意智能体深度交互。已获盛达集团战略支持与孵化，且有在线演示和视频案例（如舆情模拟、红楼梦结局推演）。但需注意，项目未提供性能基准或与同类工具的效率对比，相关优势需实际验证；且高 LLM 消耗提示对资源有限用户可能构成成本障碍。

## 设计与创新

项目创新点可能在于结合 GraphRAG 构建个体与集体记忆，并利用 OASIS 引擎实现双平台并行模拟，支持动态时序记忆更新和从上帝视角注入变量。它强调从真实世界提取种子信息来自动生成高保真数字世界，使智能体具备独立人格、长期记忆和行为逻辑，从而涌现群体智能。此外，项目设计了 ReportAgent 工具集，允许与模拟后环境深度交互。然而，这些功能的具体实现细节、与传统预测方法或其他多智能体平台的量化对比在 README 中未提供，因此创新性尚无法充分验证。

## 适用场景

根据 README，项目适用于多种场景：公共舆情事件推演（如武汉大学案例）、文学作品结局预测（如红楼梦后四十回推演）、金融信号预测和政策草案效果预演。用户可上传数据分析报告或小说故事等种子材料，用自然语言描述预测需求，系统返回预测报告和可交互数字世界。此外，宏观上可用于政策零风险测试，微观上可用于个人创意沙盒，探索各种“如果”情景。但 README 提到金融和政治新闻预测案例“即将到来”，说明这些场景尚未完全实现或验证。

## 谁会受益

项目对多智能体模拟和 LLM 应用的研究者、开发者具有参考价值，可帮助理解如何集成 GraphRAG、OASIS 等组件构建预测系统。其自然语言交互和 Docker 部署降低了使用门槛，适合快速实验。已获盛达集团支持，并有在线演示和视频案例，增强了可信度。然而，实际效用取决于模拟保真度与预测准确性，README 未提供评估指标或用户反馈，因此需谨慎评估。对于需要大规模模拟的用户，LLM 消耗可能较高，且在 40 轮以内模拟的建议暗示复杂场景可能受限。

## 使用前需要注意

项目存在若干局限：README 未说明开源许可证，使用前需确认合规性；预测准确性缺乏基准测试或量化评估，仅展示案例视频；高 LLM 消耗意味着资源成本较高，且建议模拟轮数少于 40 轮，可能限制复杂长时程推演；部分重要功能如金融和政治新闻预测仅有“即将到来”的预告，未完全实现；依赖 Zep Cloud 和外部 LLM API，可能涉及数据隐私与网络要求；技术栈较复杂，需要同时配置 Node.js、Python、uv 及环境变量，对新手有一定门槛。
