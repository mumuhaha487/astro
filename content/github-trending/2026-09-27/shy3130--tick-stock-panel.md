TSP 是一个以个人开源方式维护的 A 股量化工作台，用 Python 编写，支持自托管与 Docker 单容器部署。它把选股、指标计算、回测、因子研究、异动监控和 AI 对话助手整合在一套本地数据链路上，数据以 Parquet 本地存储，数据源采用插件化与能力路由设计，可接入第三方数据源。

## 项目做什么

项目目标是给个人研究者提供一个自托管、零运维的 A 股量化环境，把数据采集、指标流水线、选股、回测、因子检验、异动监控和复盘串成统一口径。README 明确说明它不作为投资软件或看盘软件，也不对标同花顺、通达信，不内置 AI 荐股或涨停预测，定位是学习研究用的本地量化思路与方案。

## 与同类方案相比

根据 README，其特点包括：数据源插件化与能力路由，同一数据集换源后指标与回测口径不变；全站使用统一的 enriched 数据口径；提供竞价、盘中、偏移三类异动监控，以及实时弹窗、语音播报和飞书推送；AI 对话助手可在本地数据上调用只读工具取数，并展示可核对的工具调用足迹；部署上提供 Docker 单容器与现成镜像。但这些相对同类工具的优势尚无独立验证依据，性能、稳定性等均无法从 README 证实。

## 设计与创新

README 中提到的设计点包括：按数据集能力独立路由并 fail-closed 的能力路由矩阵；交易日探针用交易日历、行情时间戳探针与工作日兜底组合判断交易日；财务数据按报告期多源取并集并按公告日取最新；回测在独立子进程中运行并支持刷新重连；enriched 存储仅保留基础列、读取时现场计算指标；后端与前端扩展目录可自动发现并挂载，删除即卸载，AI 助手即为该机制的参考实现。这些是否属于行业首创无法验证。

## 适用场景

适合有 Python 或量化基础、希望在本机或自有服务器上搭建研究环境的个人开发者。可用于配置数据源后跑盘后数据管道、用内置或自定义策略扫描全 A 股、做因子与策略回测、检验参数敏感性、记录持仓批次并生成止盈止损监控、在盘中接收异动与规则触发提醒、盘后生成 AI 复盘，以及通过对话助手用自然语言查询本地已有数据。

## 谁会受益

对个人研究者而言，项目把数据同步、指标计算、选股、回测、因子检验、监控和复盘放在同一套本地数据口径下，减少在多个脚本和工具之间搬运数据与对不齐口径的成本。插件化数据源与扩展页面便于接入自有数据，Docker 单容器降低了部署门槛，AI 助手让不熟悉页面结构的人也能直接问数据。这些价值来自 README 的功能描述，实际使用效果需自行验证。

## 使用前需要注意

README 说明项目以个人开源方式维护，仅供学习研究，不作为投资软件或看盘软件，不提供买卖指令，也不做 AI 荐股与涨停预测。部分页面标注 Beta。None 或 Free 档位下当日数据需盘后一至两小时才可用；竞价全市场扫描依赖待采集任务；财务四表适配与部分数据源专有能力存在依赖。现成镜像默认不含某些插件与老 CPU 兼容内核。性能数字、稳定性与相对同类产品的优劣尚无独立证据，需自行评估。
