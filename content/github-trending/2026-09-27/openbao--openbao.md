OpenBao 是一个用 Go 编写的敏感数据管理工具，可安全存储、动态生成和分发秘密、证书与密钥。它提供加密存储、租约续期和撤销机制，采用开源治理模式，并包含 CLI、服务端、Web UI 及官网文档。

## 项目做什么

OpenBao 旨在解决现代系统对大量秘密（如数据库凭据、API 密钥、服务间通信凭证等）的集中管理难题。它通过加密持久化存储任意键值秘密，确保即使存储被直接访问也无法读取明文；支持为 AWS、SQL 数据库等系统动态生成按需凭据，并在租约到期后自动撤销；同时提供数据加解密服务，让安全团队定义加密参数，开发者无需自行实现加密逻辑，从而降低敏感数据泄露风险并简化合规管理。

## 与同类方案相比

根据 README，OpenBao 的核心优势在于安全存储与动态秘密管理：秘密写入持久层前先加密，存储介质可为磁盘或 PostgreSQL 等，获取原始存储不足以访问秘密；可按需生成 AWS 密钥对或数据库凭据，租约到期自动撤销；所有秘密均有租约，支持内置续期 API；撤销支持单条或树状批量操作，便于密钥轮换与入侵锁定。此外，项目采用开放治理并由社区运营，官网、邮件列表、Zulip 讨论组及多个工作组提供了协作与支持渠道。

## 适用场景

OpenBao 适用于需要集中管理敏感数据的场景，例如：应用程序从 OpenBao 获取数据库凭据或云服务 API 密钥，避免硬编码；安全团队为开发者提供加解密接口，使加密数据可安全存入 SQL 数据库；服务间通信使用动态生成的短期凭证，并依靠租约自动撤销降低泄露窗口；在入侵响应时，按用户或秘密类型批量撤销凭证以锁定系统。它也适合需要密钥轮换和详细审计但不愿自建方案的团队。

## 谁会受益

对于面临秘密分散、硬编码或手动轮换困难的组织，OpenBao 提供了一套集成方案：集中加密存储秘密、按需生成临时凭据、通过租约机制自动失效、支持树状撤销以应对安全事件。仓库同时包含服务端、CLI、Web UI 和官网文档，并发布 api/v2 与 sdk/v2 库供外部项目集成。采用 Go 编写，便于熟悉 Go 的团队构建和调试，社区治理与讨论渠道也提供了协作基础。
