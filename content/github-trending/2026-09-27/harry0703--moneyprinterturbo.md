MoneyPrinterTurbo 是一个基于 Python 3.11+ 的开源 AI 短视频生成工具，用户只需提供主题或关键词，即可自动完成脚本撰写、素材匹配、配音、字幕、配乐与视频合成，支持多种大模型与素材来源。

## 项目做什么

该项目的目标是把短视频制作流程自动化，降低内容创作者的技术门槛。依据 README，用户从主题或关键词出发，系统可自动生成多语言视频脚本，匹配图片或视频素材，生成配音与字幕，添加背景音乐，并合成 9:16、16:9 或 1:1 的高清短视频。它同时提供 AI Agent、WebUI、API 和 CLI 四种入口，既服务于希望快速上手的个人用户，也面向需要把视频生成能力接入自有自动化流程或业务系统的开发者，并支持批量生成与任务历史记录。

## 与同类方案相比

依据 README 的描述，其优势主要体现在流程覆盖的完整性与可替换性上。项目把脚本、配音、素材、字幕、配乐和剪辑串联成一条工作流，每个环节又允许用户自定义，从而在自动化和可控性之间保留空间。模型服务方面同时支持 Kimi、OpenAI、Claude、Gemini、DeepSeek、通义千问等多家以及多种聚合网关和本地运行环境，素材端既有 Pexels、Pixabay 等免费库存，也支持文生视频和用户上传。此外，Edge TTS 免费且无需 API Key，成片可一键发布到 TikTok、Instagram 和 YouTube Shorts。需要注意的是，README 未提供这些能力在速度、质量或稳定性上的实测数据，因此无法据此做客观优势比较。

## 适用场景

依据 README，典型使用场景包括：内容创作者和自媒体运营者围绕一个主题批量生成多语言短视频，用于 TikTok、Instagram 和 YouTube Shorts 等平台发布；营销或运营团队通过 API 或 CLI 把视频生成接入自动化流程，并结合任务历史与批量生成能力管理内容产出；需要特定画幅与素材的用户，可利用 9:16、16:9、1:1 输出以及上传本地素材、使用库存素材或文生视频的方式定制成片；不具备部署能力的用户还可以通过第三方基于该项目提供的在线版本使用。
