WandEnhancer 是一个用 C# 开发的本地补丁工具，用于扩展 Wand（WeMod）客户端的本地配置和界面体验，支持本地环境配置、主题定制、远程 Web 面板及自定义 JavaScript 注入，官方不发布预编译可执行文件。

## 项目做什么

该项目定位为 Wand（WeMod）应用的第三方客户端侧增强与互操作性工具，通过本地文件补丁方式，为主流客户端补充配置管理、自动兼容性适配、布局主题定制以及远程控制等能力。其目标并非替代 Wand 本身，而是让用户在自己的本地安装环境中获得更灵活的界面和配置控制，项目明确声明仅用于教育、研究与本地互操作目的。

## 与同类方案相比

项目默认的 .NET 补丁器完全离线，不包含遥测或更新检查网络代码，减少数据外发；提供 GitHub Actions 工作流让用户从自己的 fork 构建可执行文件，避免依赖第三方成品二进制；内置远程 Web 面板，可通过同一局域网内手机扫码控制；支持注入自定义 JavaScript 脚本，并复用渲染器注入机制；官方发布仅提供说明、不发布 exe，以降低恶意仿冒分发风险。

## 设计与创新

README 中较具体的设计点包括：补丁器默认离线、更新通知需在编译时显式启用；Remote Web Panel 通过 QR 码在同一局域网内以 HTTP 3223 端口提供手机控制，且不传递 Wand bearer token 或安装路径字段；自定义脚本在 Wand 渲染器内运行并可访问 DOM 与 Node require，同时要求脚本自行防止多次执行。至于与同类工具的对比优势，README 未提供可验证依据，尚无法确认。

## 适用场景

适用于在 Windows 上使用 Wand（WeMod）并希望调整本地界面、主题和布局的用户；需要在新客户端版本发布后自动调整兼容性的场景；希望从手机浏览器在局域网内控制当前训练器功能的用户；愿意自行 fork、通过 GitHub Actions 构建并审查源码的技术用户；以及需要通过注入 JavaScript 修改客户端界面细节的开发者或高级用户。

## 谁会受益

对于具备一定开发基础、愿意自行构建并审查代码的用户，该项目提供了可操作的本地增强路径：离线补丁降低网络暴露面，远程面板与自定义脚本扩展了使用方式；详细的构建步骤排障说明和 Q&A 也降低了上手门槛。但由于不提供官方成品、无签名可能触发杀软警告，且部分功能依赖局域网和手动配置，其实际便利程度仍取决于用户的技术能力和对未签名工具的接受度。

## 使用前需要注意

项目不发布官方编译二进制，仅能通过 fork 后使用 GitHub Actions 自行构建，使用门槛较高；Remote Web Panel 以明文 HTTP 在 3223 端口运行且无配对码，任何能访问该端口的人都能查看和控制，仅适合可信局域网或 VPN；自行构建的程序未签名，可能被 Windows Defender 或 SmartScreen 警告；自定义脚本拥有与 Wand 客户端相同的权限，存在安全风险；README 未提供性能数据、竞品对比或许可证之外的功能验证，相关优势尚无法确认。
