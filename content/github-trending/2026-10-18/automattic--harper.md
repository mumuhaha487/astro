Harper 是一个以 Rust 编写的英语语法检查器，主打离线使用和隐私保护，并提供 WebAssembly 版本及多种编辑器集成。项目称其检查速度快、内存占用较低，但这些性能数据在此无法独立验证。

## 项目做什么

项目旨在对英语文本进行语法检查，帮助用户发现并修改写作中的问题。README 将本地处理、隐私和较快的检查响应作为设计目标，并列出 VS Code、Neovim、Helix、Emacs、Zed、Obsidian 等集成，以及语言服务器和 JavaScript 接口。

## 与同类方案相比

README 声称 Harper 可在本地运行，不必将文本发送至服务端，因此适合重视文本隐私的用户；同时提供 WebAssembly 版本，表明其可用于网页环境。项目还称检查延迟和内存占用较低，但具体测量条件、数据及独立验证结果未提供，不能据此作确定的横向结论。

## 适用场景

适用于需要检查英语文本的写作者，以及希望在编辑器中获得语法检查支持的用户；公开文档列出了多种编辑器和 Obsidian 集成。WebAssembly 版本也显示其可用于网页场景。项目目前只支持英语，README 未证明其适用于其他语言或所有类型的文本工作流。

对于希望在写作过程中本地检查英语文本、减少对云端服务依赖的用户，Harper 可作为语法检查工具候选。多种编辑器集成可能让检查融入现有写作流程，语言服务器和 JavaScript 文档也为不同接入方式提供入口。实际检查质量、规则覆盖度与特定使用需求是否匹配，仍需试用确认。
