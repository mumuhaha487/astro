YunX 是一款以 Kotlin 和 Jetpack Compose 构建的 Android 网盘解析下载应用，支持多个网盘的分享链接解析、账号登录及下载任务管理。

## 项目做什么

项目面向希望在 Android 手机上处理网盘分享内容的用户，提供从粘贴分享链接、浏览文件到获取下载直链和管理下载任务的流程。README 还列出多种网盘登录方式，并说明应用仅面向 Android。

## 与同类方案相比

README 列出夸克、UC、迅雷、百度、123、139、115、光鸭和蓝奏云等服务的链接解析支持，并称可自动匹配提取码。下载部分提供分片并发、断点续传及暂停、继续、删除等操作；这些描述来自项目文档，实际效果需结合设备和网盘账号验证。

## 设计与创新

项目描述的实现组合包括针对多个网盘的解析与登录、Range 分片并发下载、断点续传以及加密认证信息备份。README 未提供与其他应用的技术对比、原创算法说明或独立验证材料，因此无法据此确认其创新程度或独特性。

## 适用场景

适用场景包括在 Android 设备上粘贴受支持网盘的分享链接、查看分享文件并发起下载，以及管理下载进度。用户需先按需登录对应网盘；README 提醒百度网盘可能触发账号风控，因此使用该平台时应留意账号风险。

## 谁会受益

对于需要在手机上集中处理多种网盘分享链接的用户，应用提供了从链接解析到下载管理的一站式操作入口，也支持复制链接后的剪贴板提示。其实际便利性取决于各网盘接口、账号状态、网络环境及当前版本的兼容情况。

## 使用前需要注意

项目仅支持 Android，README 标明最低 Android API 级别为 24、目标级别为 34；其他网盘暂未支持。文档提示百度网盘可能导致账号被风控，且部分网盘功能依赖账号认证。README 的功能与兼容性声明尚不能独立验证，下载权限、服务变更影响及实际稳定性也未在所给材料中充分说明。
