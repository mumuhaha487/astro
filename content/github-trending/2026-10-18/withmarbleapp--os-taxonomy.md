Marble Skill Taxonomy 是面向小学阶段学习内容的结构化数据集，以微主题、先修关系和课程标准映射组织跨学科知识，并提供 JSON 数据与结构说明。

## 项目做什么

项目旨在把儿童在小学阶段学习的内容拆分为细粒度、可描述的微主题，并将主题之间的先修依赖和课程标准关联起来。README列出八个学科及主题数据、依赖边、课程标准和领域摘要，供使用者读取和处理。

## 与同类方案相比

按项目说明，主题条目包含名称、描述、学科领域、年龄范围、掌握证据、评估提示和标准引用；依赖关系带有强弱标记与文字理由。数据以 JSON 提供，并附有 JSON Schema、清单及校验脚本，便于检视结构和引用关系。

## 设计与创新

项目将微主题、带理由的有向先修关系以及多套课程标准映射放在同一数据结构中，并提供面向家长的领域摘要。README称其不同于平面标准清单，但没有给出与其他数据集的系统比较或评估，因此其独特性和实际改进幅度尚无法验证。

## 适用场景

可用于构建课程内容浏览器、展示某一主题的前置知识路径、按年龄或学科筛选学习主题，或将主题与所列课程标准关联。也可用于教育内容管理或研究原型；这些是基于数据字段推导的可能用途，并非README证明已实现的应用。

## 谁会受益

对需要可机器读取的学习主题清单和依赖关系的开发者或研究者，数据文件、稳定主题标识、标准键值及依赖方向说明具有参考价值。README还给出JavaScript读取示例和校验命令；数据是否适合特定教学体系，仍需按实际内容和来源核对。

## 使用前需要注意

README描述了数据规模与字段，但未提供主题编制、年龄分配及依赖审核方法，也未给出准确性或教学效果评估，不能据此确认覆盖完整或适用于所有地区。发布内容不含语义嵌入和个人学习数据；第三方课程标准各有来源许可，使用前需查阅其来源说明及适用条款。
