Rakazo 是一款以 TypeScript 构建的开源、自托管 AI 智能体，支持持久化机器人、用户自选模型与计算机运行环境，并提供网页、桌面及移动端客户端。

## 项目做什么

项目旨在让用户创建并通过聊天管理长期运行的 AI 机器人。机器人可保存对话、记忆、例程与历史记录，并使用浏览器、终端、文件和图形桌面等计算机能力；用户可连接自己的模型，也可自行部署完整服务栈。

## 与同类方案相比

README 说明，Rakazo 提供多种部署入口，包括 Docker Compose 自托管、服务器部署和桌面端本机运行；客户端还覆盖网页、Electron、iPhone 与 Android。模型、语音服务和沙箱计算机提供方可按需配置，部分集成也可由用户自行添加。以上是功能与配置灵活性的描述，不能据此推断其性能或成本更优。

## 设计与创新

README 将 Rakazo 描述为持久化 AI 队友，并列出机器人间委派、短期子代理、共享团队计算机及隔离私有计算机等能力。不过，现有材料仅能确认这些功能被项目列出，不能证明其相对其他智能体具有技术创新，也不足以验证与 README 所列产品的实际差异。

## 适用场景

适合希望自托管聊天式 AI 助手、选择模型供应商并让机器人保留长期对话与例程的个人或团队；也可用于需要机器人操作浏览器、终端或文件的任务。若要在服务器上持续运行机器人，可按文档配置沙箱提供方与 HTTPS，再从网页、桌面或移动端连接。

## 谁会受益

项目提供从发布镜像快速启动到源码开发的路径，并附有自托管、密钥管理、计算机运行时、备份升级及客户端发布文档。其 TypeScript、React、Hono、PostgreSQL、Prisma 等技术栈，以及 lint、类型检查、测试和端到端测试命令，可为部署者和贡献者提供明确的操作入口。

## 使用前需要注意

项目处于 beta 阶段，README 未给出可独立核验的稳定性或性能数据。部署和使用可能需要 Docker、数据库、模型凭据及沙箱或集成服务的密钥；语音、托管应用目录等能力也涉及外部服务配置。不同客户端的语言支持并不完全一致。README 虽称其为其他产品的替代方案，但不足以验证比较结论或优势。
