RuView 是一个基于 Rust 的 WiFi 感知平台，利用低成本 ESP32 传感器的 CSI 数据，实现穿墙人员检测、生命体征监测（呼吸和心率）、活动识别、睡眠监测和 17 关键点姿态估计，无需摄像头，支持本地边缘运行和主流智能家居集成。

## 项目做什么

该项目的核心目标是将普通 WiFi 信号转化为空间智能传感器，通过捕捉人体对无线电波的扰动，在不使用摄像头或可穿戴设备的前提下，实现非接触式的人员存在检测、生命体征测量、活动识别及环境映射。它旨在为智能家居、养老监护、安防和健康监测等场景提供隐私友好的感知能力，并支持本地自动化与边缘计算。

## 与同类方案相比

根据 README，RuView 的优势包括：无需摄像头，保护隐私；使用低成本 ESP32 硬件（约 9 美元/节点），总物料成本可低至 140 美元；完全在本地边缘运行，无需云服务或互联网；支持与 Home Assistant、Apple Home、Google Home、Alexa 等智能家居生态原生集成；内置边缘智能模块目录（105 个 Cog）；支持加密认证和证据链记录；模型量化后仅 8 KB，可在树莓派上微秒级运行。

## 设计与创新

README 中说明的创新点包括：利用邻居路由器作为免费雷达照射源的多频段网格扫描；通过 CSI 实现摄像头无关的姿态估计（17 个关键点）；自监督对比学习预训练编码器，支持本地快速微调；统一 RF 世界模型，融合 WiFi、雷达、UWB 等信号；提供链上证据治理和不确定性追踪；MetaHarness 工具用于 AI 辅助校准与验证；以及精确到模型准确率（如 82.3% 的时序三元组准确率）的诚实基准测试。

## 适用场景

README 中列出的典型应用场景涵盖：家庭存在检测与房间占用统计；老年人或独居者呼吸与心率监测，睡眠质量分析及呼吸暂停筛查；跌倒检测与风险预警；多人员计数与轨迹追踪；办公室会议室占用状态；零售客流统计与排队长度监测；工业洁净室人员管理；以及通过 Matter 桥接实现智能家居语音查询。

## 谁会受益

该项目对需要隐私保护、穿墙感知且预算有限的用户具有较高实用价值。它避免了摄像头带来的隐私问题，并支持在无网络环境下本地运行，适合家庭监护、养老院、智能楼宇和安防领域。与 Home Assistant 等平台的无缝集成降低了部署门槛，而预训练模型和边缘模块目录进一步简化了定制化开发。然而，实际效果高度依赖硬件配置（需 CSI 支持）和环境校准。

## 使用前需要注意

README 中明确指出的局限性包括：必须使用支持 CSI 的硬件（如 ESP32-S3 或研究网卡），普通消费级笔记本只能提供 RSSI 级别的存在检测；穿墙感知距离通常限制在约 5 米以内，且受信号强度影响；摄像头无关的姿态估计在当前设备端模型上的 PCK@20 仅为 3.0%，远低于 35% 的目标准确率，运行时路径仍为置信度 0 的占位；统一的 RF 世界模型准确性仍基于合成数据，尚未经真实数据验证；部分功能（如 TWT 和微安级休眠）仍需硬件验证。
