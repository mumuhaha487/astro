## 项目做什么

该仓库的核心目的是为 qBittorrent 的搜索功能提供可用的搜索插件，使用户能够通过 qBittorrent 界面搜索多个资源站点。仓库本身并不直接开发 qBittorrent 主程序，而是作为第三方贡献者分享和维护插件的集散地，README 明确指向 wiki 以获取非官方插件列表和安装指导，同时提醒用户自行承担使用风险并遵守当地法律。

## 适用场景

该仓库适用于使用 qBittorrent 并希望利用其内置搜索功能查找资源的用户。用户可以通过安装仓库中的插件，扩展 qBittorrent 的搜索能力，覆盖不同的资源站点。开发者或贡献者也可以参考 README 中指向的 wiki 指南，学习如何编写新的搜索插件或修复现有插件。此外，需要配置 Jackett 插件的用户也能从 wiki 中获得指导。

对于 qBittorrent 用户而言，该仓库提供了搜索插件的官方来源，配合 wiki 文档能够帮助用户快速找到、安装和配置插件，从而增强 qBittorrent 的搜索体验。对于开发者，README 指引了如何编写和贡献插件，有助于社区协作。但 README 也明确表示目前缺乏维护额外官方插件的能力，只欢迎修复现有插件的 PR，因此其直接可用性和扩展性可能受限于社区贡献的活跃程度。
