Free Claude Code（FCC）是以 Python 实现的模型与编码代理接入工具，通过本地管理界面和代理服务，将多家模型提供方连接到多种编码客户端。

## 项目做什么

项目旨在让用户从统一的 Admin UI 配置模型、提供方与回退选项，再通过启动命令在终端、IDE 等环境中使用编码代理。README 列出 Claude Code、Codex、Pi、OpenCode 等 11 种代理，并介绍浏览器会话及桌面、编辑器和消息平台接入方式；其支持范围和可用性以具体集成及提供方条件为准。

## 与同类方案相比

README 描述了统一的模型目录、可添加自定义 API 提供方，以及按顺序配置备用模型的能力；请求失败后可尝试后续模型。它还列出 RTK、Headroom 等可选工具，并称有若干无需调用提供方的本地优化。实际节省量、故障切换效果及对各客户端的兼容程度，不能仅凭文档宣称独立验证。

## 设计与创新

文档强调在多种编码代理与提供方之间共用配置，并称浏览器中可运行原生 Codex 会话、在同一会话切换提供方或模型；跨代理切换则标为计划中。多代理统一接入、会话切换及其他设计是否构成相对现有工具的创新，缺少对照资料，尚无法验证。

## 适用场景

适用于希望在一个本地管理界面中配置不同模型服务，并通过熟悉的编码代理或编辑器开展开发工作的用户；也可用于尝试本地模型、订阅登录或云端 API 等不同接入方式。README 还提及浏览器代码会话、Discord、Telegram 和语音转录，但实际可用性取决于所选集成、账号、系统环境及相关服务。

## 谁会受益

若用户需要集中管理多种模型凭据、为编码代理选择模型，或配置请求失败后的备用模型，FCC 提供了相应入口和客户端启动命令。它也说明如何配置自定义端点及本地代理认证。对于具体提供方是否有免费额度、模型是否适合编程、优化是否有效，仍需按提供方规则和实际测试判断。

## 使用前需要注意

项目对多种外部服务和客户端有依赖，需按配置提供 API 密钥、完成 OAuth 登录或准备本地模型服务；免费额度及限制由各提供方决定且可能变化。README 提到回退请求可能消耗多个提供方的用量，部分模型或功能有兼容条件。所给材料不能独立证实宣传的免费令牌总量、用量下降幅度或所有集成的当前状态。
