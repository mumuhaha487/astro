该仓库保存阿波罗11号指令舱与登月舱制导计算机的原始汇编源码转录，分别对应 Comanche055 和 Luminary099。项目以对照原始扫描件校订、补全文件为目标。

## 项目做什么

项目旨在集中保存阿波罗11号任务相关的 AGC 程序源码：Comanche055 属于指令舱程序，Luminary099 属于登月舱程序。README 说明源码由 Virtual AGC 与 MIT Museum 相关人员数字化转录，欢迎针对转录与原始扫描件之间的差异，以及可能遗漏的文件提交修订。若要编译源码，README 指向 Virtual AGC。

## 与同类方案相比

仓库将两套与阿波罗11号相关的程序源码及其版本标识集中呈现，并提供转录来源、对应原始扫描件和历史审批信息等背景，便于研究者追溯材料来源。README 也明确说明校订依据和贡献方向，有助于发现转录误差；但这些信息并不能证明源码已经完全校验或适用于现代运行环境。

## 设计与创新

从给定简介与 README 看，项目重点是保存和校订历史源码转录，而非提出新的算法、编程语言或制导技术。README 提到 Comanche055、Luminary099、扫描件来源及多语言说明，但没有提供足以确认技术创新或相较其他源码档案之独特优势的依据，因此相关比较尚无法验证。

## 适用场景

适用场景包括查阅阿波罗11号指令舱和登月舱 AGC 程序文本、研究早期航天软件与汇编代码、核对数字转录是否符合原始扫描件，以及了解相关程序的历史版本和审批背景。若需要汇编或运行源码，README 建议使用 Virtual AGC；仓库本身是否包含完整构建流程，依据现有说明无法确认。

## 谁会受益

对于航天史、软件史和汇编语言研究者，仓库提供可检索的源码文本，并将其关联到具体程序名称、修订版本与历史材料来源，能作为查证和学习的入口。对于希望编译源码的用户，README 给出了外部工具项目的指引；不过仓库是否独立提供工具链、测试或运行示例，现有信息没有说明。

## 使用前需要注意

README 将内容描述为从 MIT Museum 的硬拷贝数字图像转录或改编而来，并邀请用户继续比对原始扫描件，因此不应假定文本无误或完整。编译依赖被引导至 Virtual AGC，未说明仓库自身的构建步骤和运行验证情况；源码适用范围也限定在所列历史程序。项目许可证等法律信息未在给定材料中得到充分确认，不能据此作进一步判断。
