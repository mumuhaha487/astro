Folia 是一款以全屏歌词动画为核心的音乐播放器，支持本地曲库、多个在线音乐来源及 Navidrome，并提供 Web 与桌面端形态。

## 项目做什么

项目面向希望以歌词视觉呈现为主要听歌体验的用户，提供歌曲搜索与播放、歌词加载和全屏动画展示。它也支持导入本地音乐并匹配歌词与封面，兼顾在线曲库和个人音乐文件的管理与播放。

## 与同类方案相比

README 列出的能力包括多种歌词动画及可调参数、响应式布局、本地歌词文件识别和在线歌词匹配；用户可在 Windows、macOS、Linux 桌面端或 Web 版本使用。部署方式涵盖托管平台、自托管和 Docker Compose，但实际使用效果取决于设备、配置及音乐服务可用性。

## 设计与创新

项目将歌词动画、歌曲相关主题生成和可扩展模组纳入同一播放器体验，并支持模组增加动画、背景或播放页图层。README 将模组系统标为实验性功能，且仅桌面版可用；仅凭仓库简介和 README，无法验证这些设计相较其他播放器是否构成独有创新。

## 适用场景

适用于偏好全屏歌词与视觉效果的个人听歌场景，也可用于播放本地音频、调用网易云或酷狗等在线来源，以及接入 Navidrome。需要跨设备体验的用户可部署 Web 版本；桌面用户还可连接本机 Now Playing 服务或尝试实验性模组。

## 谁会受益

如果用户希望把歌词展示作为音乐播放界面的重点，Folia 提供了动画选择、歌词和封面匹配、主题生成等相关功能。本地曲库流程还支持读取同目录歌词文件并手动修正匹配结果；是否适合具体服务、设备和部署环境，建议结合使用指南与实际测试判断。

## 使用前需要注意

README 未提供可用于比较的性能或稳定性数据，也不足以确认各音乐来源在不同地区和部署环境中的持续可用性；本地音乐目录访问有安全上下文要求。模组系统仍属实验性且运行可信代码，在线内容涉及版权，部署者和用户需要自行核对服务条件、授权与安全风险。
