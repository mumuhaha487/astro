Vorssaint 是面向 Apple Silicon Mac 的免费开源菜单栏工具集，用 Swift 编写，需 macOS 14 及以上。它把音量混合、系统监控、窗口管理、剪贴板历史、截图录屏、应用清理等常见工具聚合到单个菜单栏图标下，功能按需安装，强调本地优先、无账号与遥测。

## 项目做什么

项目旨在把 macOS 用户通常需要逐款付费购买的小工具整合到一个免费开源的菜单栏应用里，覆盖音频、系统监控、窗口与 Dock、键盘鼠标、剪贴板、截图录屏、应用管理和电源显示等多个日常场景。它面向希望减少订阅与隐私顾虑的 Mac 用户，提供按需安装的功能中心，用户可只启用自己需要的模块，未安装的功能会停止加载并从界面隐藏，设置还能导出到另一台 Mac。

## 与同类方案相比

从 README 看，其优势集中在开放性、隐私和模块化三方面：源码采用 GPL 3.0 或更高版本，官方构建经 Apple Developer ID 签名并公证，权限通过更新保留；默认本地优先，无账号、分析或跟踪，网络仅在更新检查、测速、Homebrew、在线歌词、临时分享链接和主动反馈时使用；功能可单独安装卸载，权限按所选功能申请，并会提示已不再被使用的权限。其相对付费同类工具的实际优势尚无独立基准可验证。

## 设计与创新

README 描述了一些较有辨识度的能力：无需音频驱动的按应用音量混合与超过 100% 的音频增强，Dynamic Island 形式承载音乐、通知、日历、下载和 AI 代理状态，径向菜单与命令栏把应用、窗口、文件、剪贴板、片段和脚本聚合到一个入口，以及风扇控制测试版、清洁模式和按应用退出保护等。由于缺少与既有实现的对比资料，这些功能是否属于首创或显著创新目前无法验证。

## 适用场景

适用场景包括：需要为不同应用单独调节音量或把音乐与通话分流到不同输出设备；想快速查看 CPU、GPU、内存、温度、电池与网络流量；频繁切换窗口、使用 Dock 预览和窗口吸附布局；依赖剪贴板历史、文本片段、文件暂存架和 Finder 快捷键；进行截图、录屏、OCR、取色和本地媒体转换；以及通过清理、卸载、Homebrew 管理、端口管理、保持唤醒、显示器亮度和蓝牙睡眠管理等维护 Mac。

## 谁会受益

对使用 Apple Silicon 且系统为 macOS 14 及以上的用户，如果原本需要安装多个独立菜单栏小工具，该项目提供了统一入口和一致的设置、快捷键与权限管理，减少应用数量并集中控制。模块可按需安装，也有 Homebrew 安装方式和自建脚本，源码可见便于审查。其实际稳定性、性能占用和对不同 Mac 配置的兼容性，README 未给出可验证数据，需自行试用评估。

## 使用前需要注意

已知限制包括：仅支持 Apple Silicon，且需 macOS 14 Sonoma 或更新；部分功能依赖特定权限，如音乐应用拦截需要辅助功能权限；风扇控制标注为测试版；某些能力依赖硬件或系统支持，例如 XDR 额外亮度、硬件亮度控制和输入设备的麦克风电平调节。项目未提供性能、稳定性或与其他工具的对比验证；名称、图标和外观受商标文件约束，分支需使用独立品牌；官方构建仅来自维护者。
