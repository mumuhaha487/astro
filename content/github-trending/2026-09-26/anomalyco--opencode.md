OpenCode 是一个用 TypeScript 编写的开源 AI 编码代理，提供终端用户界面和桌面应用测试版，支持通过多种包管理器安装，并内置 build 与 plan 两种可切换代理。

## 项目做什么

该项目旨在为开发者提供一个开源、可本地安装和使用的 AI 编码助手，通过终端界面或桌面应用与 AI 交互完成开发任务。从 README 可见，它提供了 build 和 plan 两类代理：build 为默认全权限代理，用于开发工作；plan 为只读代理，用于分析代码和探索陌生代码库，并在执行 bash 命令前请求许可。此外还有 general 子代理用于复杂搜索和多步骤任务。项目提供详细的安装方式，支持 npm、brew、scoop、pacman、nix 等多种包管理器，说明其定位是覆盖多平台、易安装的通用编码代理工具。

## 与同类方案相比

根据 README，OpenCode 的优势主要体现在安装与分发的便利性上：覆盖 macOS、Windows、Linux 及多种包管理器，并提供一键安装脚本和桌面应用下载。其内置的 build 与 plan 双代理模式，使开发者能在开发与只读分析两种场景间切换，plan 代理默认拒绝文件编辑并要求 bash 命令授权，有助于在探索陌生代码库时降低误操作风险。项目还提供多语言 README 和 Discord 社区，说明其重视国际化与社区协作。但 README 未提供性能数据、与其他编码代理的对比，因此无法验证其在速度、准确性或功能完整度上的相对优势。

## 设计与创新

从 README 可观察到的设计特点包括：以终端用户界面为主要形态，并额外提供桌面应用测试版；内置 build 与 plan 两种权限模型不同的代理，通过 Tab 键切换，plan 代理默认只读并要求命令授权，体现对操作安全的考虑；general 子代理可通过 @general 在消息中调用，用于复杂搜索和多步骤任务。README 还明确要求基于 OpenCode 构建的第三方项目声明非官方关联。但 README 未描述底层模型调用机制、上下文管理或与其他工具的技术差异，因此其创新性是否显著尚无法仅凭现有信息验证。

## 适用场景

README 明确说明的适用场景包括：日常开发工作时使用默认的 build 代理；探索不熟悉的代码库或规划变更时使用只读的 plan 代理；执行复杂搜索和多步骤任务时通过 @general 调用 general 子代理。安装方式覆盖 macOS、Windows、Arch Linux、Nix 等多种环境，并支持通过 mise 在任意操作系统使用，适合偏好终端工作流的开发者，也适合希望通过包管理器统一管理工具的团队。桌面应用测试版则面向偏好图形界面的用户。README 未列举具体行业或项目类型，因此这些场景属于基于功能描述的直接推断。
