ChinaTextbookStudyFree 是面向中国小学一至六年级的免费学习平台，覆盖语文、数学、英语和科学，提供单元练习、课文听读、课外阅读及学习记录等功能，并支持 Web 与 iOS。

## 项目做什么

项目旨在汇集小学阶段的教材知识与配套学习资源，降低学生获取练习和阅读材料的门槛。平台围绕教材单元组织课程，结合题目讲解、语音朗读、课文原页和分级故事，服务家庭自学及课堂外巩固；项目简介强调公益定位，但实际学习效果需由使用者判断。

## 与同类方案相比

README 声称项目免费、无广告，并提供公开的代码和资源获取方式；不过教材文本与页面图片版权归各自权利人，项目代码许可不代表教材资源可自由再利用。平台覆盖面、功能和资源数量可从文档描述了解，但实际可用性、教学成效、内容准确性及与其他产品的比较优势，尚不能仅凭 README 独立确认。

## 设计与创新

README 展示了多种产品设计组合，例如答题即时反馈、语音讲解、学习奖励与装扮系统，以及首次听完讲解后解锁下一步的交互。内容生成流程使用 AI 辅助制作题目、故事和配图，并说明教师复核仍在进行。仅依据仓库简介和 README，无法验证这些设计相较其他学习产品是否具有独创性或实际优势。

## 适用场景

适用场景包括小学生按教材单元进行课后练习、通过语音和课本原页复习语文或英语课文、阅读分级故事并完成理解题，以及家长查看本地学习记录和设置每日学习时间限制。电脑和手机浏览器均可使用；iOS 客户端面向 iPhone 与 iPad。跟读录音需要 HTTPS 和麦克风授权。

## 谁会受益

对于希望集中使用多学科练习、朗读材料和阅读资源的学生或家庭，平台提供了相对完整的自学入口；对教师和开发者，也提供题库生成流程、内容审核参与方式及 Web、SwiftUI 工程结构。README 明确提示题目并非全部经过教师逐题审核，因此更适合作为辅助练习资源，而不宜仅凭其内容替代教材或教师指导。

## 使用前需要注意

资源数据、音频、配图和课本页图需另行下载，安装包约 2.06 GB，首次启动还会进行音频转换。Web 学习记录仅存于当前浏览器，清除浏览器数据可能导致记录受影响；暂无云同步、教师端和离线部署包。README 记载有 1,498 课缺少讲解、1,183 课仅有一道题，且部分课程仍待补齐；跟读暂不提供语音识别评分，真实设备兼容性也仍需复核。
