LibreTV 是基于 Next.js 15 与 TypeScript 的自托管影视搜索和播放平台，支持聚合第三方点播源、直播 IPTV、Docker 部署及本地观看记录管理。

## 项目做什么

项目旨在把用户配置的第三方影视采集接口与直播播放列表集中到一个可自托管的网站中，提供搜索、选源、播放和直播频道浏览等功能。它不内置或制作影视内容，实际可用内容取决于用户添加的数据源及其合法性与稳定性。

## 与同类方案相比

README 描述了 Docker 镜像和源码构建等部署路径，并提供环境变量配置、点播与直播源管理、订阅导入导出及配置迁移。搜索可并行查询多个来源，单源失败不阻断整体结果；播放进度保存在本机 IndexedDB，另有跨源切换、自动连播、亮暗主题和 PWA 等功能。以上为文档所述能力，实际运行效果未在材料中独立验证。

## 设计与创新

README 列出了跨源同名影片聚合、换源测速、源健康度自动停用、兼容部分 TVBOX 配置的订阅导入，以及点播与直播源共用订阅格式等设计。它们可视为该项目提供的功能组合，但现有材料不足以证明这些做法具有行业首创性，也无法据此确认相较其他项目的技术优势。

## 适用场景

适用于希望在自有服务器或本地环境搭建影视聚合入口的用户，也适合需要统一管理多个 Apple CMS 点播接口和 M3U 直播订阅的场景。部署者可预置来源供使用者访问；个人用户可搜索影片、观看直播、保存续播位置，并导出订阅或观看记录相关配置。使用前需自行确认数据源可访问且内容使用合规。

## 谁会受益

对于已有合规第三方数据源、希望集中搜索和播放的用户，项目提供了从部署、源配置到观看的较完整工作流。管理员可通过 Docker、密码和环境变量控制站点配置，用户可在设置中维护来源并通过订阅分发列表。其价值主要在于整合来源与播放界面，不代表项目提供视频资源或保证来源长期有效。

## 使用前需要注意

运行依赖外部点播接口、直播列表及其播放地址，来源失效、格式差异或上游限制可能影响搜索与播放。生产部署需配置访问密码并通过 HTTPS 提供服务；代理存在 SSRF 限制，内网直播源默认不可用，需部署者显式开启。观看进度保存在本机而非跨设备同步。README 未提供独立测试结果、运行性能数据或与其他项目的可验证对比，许可证信息也未在所给材料中说明。
