基于 Claude Code 的求职申请框架，支持职位评估、简历定制、求职信撰写与面试准备。用户需自行分叉并填写个人资料，工作流在本地运行。

## 项目做什么

该项目旨在将 Claude Code 转化为求职申请助手，通过结构化工作流覆盖从个人资料设置、职位搜索与匹配评估，到简历与求职信生成、面试准备及申请结果跟踪的完整流程。核心工作流（自我剖析、适配评估、起草-审核应用流水线）与语言和国家无关，但职位门户搜索技能目前主要面向丹麦市场，设计上可替换为其他地区的招聘网站。项目作者用自己的求职经历验证了该框架，供他人分叉后按自身情况使用。

## 与同类方案相比

项目提供了一套完整的求职辅助工作流，包括多职位门户搜索、基于五维评估框架的职位匹配评分、LaTeX 格式的简历和求职信自动生成，以及由第二代理进行审核和修订的起草-审核流水线。它还涵盖面试准备、结果跟踪、Gmail 状态同步和 Notion 看板同步等扩展功能。技术栈要求明确，包括 Claude Code CLI、Python 3.10+、Bun 和 LaTeX 发行版。帖子被视为不可信输入，不执行其中嵌入的指令，并提供了安全说明文档。

## 设计与创新

其创新点可能在于将起草-审核双代理流水线应用于求职材料生成，并结合了职位匹配评分框架。它预置了针对丹麦市场的多个招聘门户搜索 CLI 工具，并设计了可扩展的 /add-portal 命令用于生成新的门户搜索技能。此外，项目采用 Claude Code 的自定义命令和技能机制来编排工作流，并提供了可选的薪资基准参考和从 Gmail 中自动提取申请状态的尝试。但这些特点是否构成相对于其他工具的显著创新，尚无充分依据可验证。

## 适用场景

适用于正在求职的开发者或技术从业者，希望通过自动化工具辅助评估职位匹配度、快速生成定制化简历和求职信、准备面试，并跟踪申请进展。特别适合需要高效管理多个申请、希望利用本地运行和分叉机制保护隐私的用户。该项目也可用于学习如何基于 Claude Code 构建自定义工作流。由于门户搜索技能主要针对丹麦市场，非丹麦用户可能需要使用 /add-portal 扩展本地招聘网站，或直接粘贴职位描述使用核心功能。

## 谁会受益

对于熟悉 Claude Code 和 LaTeX 并希望系统化求职流程的用户，该项目能显著减少重复性文书工作，提供结构化的评估和材料生成。其分叉模式允许用户完全掌控数据，并可按需调整评估标准和模板。扩展命令如 /rank、/interview 和 /outcome 增强了流程的连续性和跟踪能力。然而，实际效果取决于用户个人资料的完整性和 Claude Code 的获取成本，且缺少免费的替代方案可能增加使用门槛。作者的个人成功案例无法直接推广到所有用户。

## 使用前需要注意

项目依赖 Claude Code，而 Claude Code 没有免费层级，需要订阅或 API 额度，这构成了使用成本门槛。LaTeX 编译需要特定发行版和引擎（lualatex 和 xelatex），对不熟悉 LaTeX 的用户可能造成困难。职位门户搜索技能主要面向丹麦市场，其他地区用户需要额外配置或改用粘贴描述的方式。代理的安全防护仅为指令级别，并非沙箱，用户在陌生招聘网站使用时仍需自行检查抓取和生成的内容。此外，项目未提供性能基准、与其他竞品的对比或独立验证，声称的效用主要基于作者个人经历，尚无法普遍验证。
