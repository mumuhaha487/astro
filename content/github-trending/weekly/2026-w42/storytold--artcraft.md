ArtCraft 是面向艺术家、设计师与影视创作者的交互式 AI 图像和视频创作桌面工具。它把提示词生成与二维画布、三维场景搭建及多类生成模型结合，强调先构图、再生成，以视觉操作获得更可控、可重复的创作结果。

## 项目定位与要解决的问题

项目将自己定位为“面向艺术家的 IDE”，重点不是单次输入提示词后取得一张结果图，而是把构思、场景规划、素材组织与 AI 生成放进同一套创作环境。README 所说的“精确、可重复”是项目方对目标的描述，并非经独立验证的性能结论。目标用户包括需要控制构图、角色身份、镜头位置和场景关系的艺术家、设计师与影视创作者；应用提供 Windows、macOS 稳定版本，源码构建文档也提及 Linux。

## 核心能力

核心创作方式是在生成前先搭建画面。二维方向包含图层合成、绘制、抠图、蒙版、修补和画布编辑；三维方向包含背景、前景、道具和网格对象的组合、空间定位与镜头取景，也提供角色摆姿、场景阻挡及身份迁移等流程。用户可以从文本提示快速探索，也可以用图像编辑、图生视频等方式继续加工。README 展示的是功能范围与示例，并未说明每项能力的内部实现或质量指标。

## 技术结构与实现思路

模型目录显示其集成策略不局限于单一生成品类：图像部分列有 Nano Banana、GPT Image、FLUX、Seedream；视频部分包括 Seedance、Kling、Veo、Sora、Vidu、MiniMax 和 Flux；另有 Suno、Seed Audio、Hunyuan 3D、Tripo3D、Meshy、Rodin、Marble 与 TripoSplat 等系列。目录注明个别模型已停用，另有模型受限且尚不可在桌面应用使用；Kling、Google、Runway、Luma 等新增集成仅属计划，现有订阅聚合服务也只是项目方表达的兴趣，并非已实现能力。

## 实际工作流程

典型流程可以从文本提示开始，用图像模型探索视觉方向；随后把结果带入画布，通过绘制、蒙版、背景移除或提示式编辑调整局部；需要更明确的空间关系时，可在二维图层或三维场景中组合素材、安排角色和道具、确定镜头与构图，再生成目标画面。已有图像还可作为图生视频的输入。README 也展示了图像转三维网格、同一环境规划多镜头等用途，但没有给出项目文件格式、步骤自动化程度或各模型之间的兼容细节。

## 与同类方案的取舍

项目最明确的区分方向，是把视觉构图工具与多家生成模型并置：用户不必只依赖文字描述，而可用图层、空间位置、角色姿态和摄影机取景表达意图，再选择相应模型完成生成。其示例覆盖二维合成、三维合成、场景搭建、角色控制以及图像与视频生成，体现出“创作过程可视化”的产品思路。README 未提供与其他软件的直接对比、基准测试或结果一致性数据，因此不宜据此断言其控制能力或效率优于其他方案。

## 值得关注的设计

ArtCraft 将提示生成、二维画布编辑与三维场景搭建置于同一创作流程，试图把生成式影像从单次描述转为可规划、可调整的视觉制作。

## 适用领域和具体场景

README 展示的工作方式覆盖从快速探索到镜头规划：用户可用文本生成或提示词编辑图像，再通过绘画、遮罩和局部修补指定修改区域；也可移除背景、叠加二维图层，或在三维空间布置背景、前景与道具。角色姿势、相机位置和场景阻挡等工具面向多镜头构思；图像转视频、图像转三维网格，以及图像、世界和网格混合，则拓展到动态分镜和复合场景制作。

## 哪些人会受益

项目将艺术家、设计师和电影创作者列为目标用户，尤其适合希望在生成前先安排构图、角色身份、姿势或摄影机位置的人。只想快速尝试视觉方向的用户也可从提示词生成开始，再进入画布或场景工具细化结果。它更像面向视觉创作过程的桌面工作环境，而非仅提供单一生成入口；不过 README 没有说明专业团队协作、资产管理或特定行业流程的支持程度。

README 提供 Windows 和 macOS 稳定版下载、GitHub 最新构建以及包含 Linux 的源码构建指引，并链接开发文档、路线图和桌面开发脚本；项目采用 MIT 或 Apache-2.0 双许可证。它列出图像、视频、音乐与声音、三维网格、世界生成等模型目录，并提及 Grok、Midjourney、Sora、World Labs 等提供方。不同模型的可用状态并不一致，部分标为禁用或桌面应用暂不可用；Kling、Google、Runway、Luma 等集成仍属计划，不能视为已交付。
