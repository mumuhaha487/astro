AnyPS5 是一款以 C++ 实现的 PS5 可执行文件移植工具，目标是在 Linux 和 Windows 上运行相关程序。

## 项目定位与要解决的问题

项目定位于 PS5 可执行文件向 Linux、Windows 的移植与兼容，而非提供完整主机模拟器。其简介强调通过转换可执行文件格式并实现系统 PRX 库来适配目标环境；项目也将互操作、研究、软件保存与兼容列为用途。实际兼容程度应以项目提供的已验证游戏列表和已知问题为准，不能据此推断所有 PS5 程序均可运行。

## 核心能力

核心由两类工作构成：relinker 将可执行文件转换为目标系统的原生格式，core/libs/prx 中的系统库实现则用于动态链接。项目称不采用模拟或独立运行时进程。另有着色器重编译器，README 表示其能够生成 SPIR-V，并可在启用 ANYPS5_ENABLE_SPIRV_TOOLS 时借助 Spirv-Tools 验证。系统库进度指标统计的是项目目前已知并声明的函数占比，并非全部 PS5 系统函数的覆盖率。

## 技术结构与实现思路

从仓库简介可见，代码按可执行文件重链接、PRX 系统库和着色器重编译等职责划分，且分别指向 core/relinker、core/libs/prx 与 core/shader/recompiler/Recompiler.cpp。这个结构体现出先处理目标格式与链接依赖、再由对应实现承接系统接口的路线；但 README 未给出模块间调用细节、支持的二进制格式范围或完整执行时序，因此不宜进一步断言其内部机制。

## 实际工作流程

使用者可先查阅 docs/user/USAGE.md 获取使用说明，并参考 docs/user/COMPATIBILITY.md 判断具体游戏是否经过测试及存在哪些已知问题。输入方面支持 SDL 映射的手柄，包括摇杆和扳机；键盘、鼠标控制可通过 anyps5-input.ini 配置。开发者可查看构建、架构、技术债务与代码规范文档。对于不支持或意外状态，项目说明会抛出 std::runtime_error，将 what() 输出到标准错误后终止进程。

## 与同类方案的取舍

项目明确提出的路线特点，是将可执行文件转为目标系统原生格式，并以可动态链接的系统 PRX 库实现配套接口，同时声明不使用模拟或独立运行时进程。这些属于项目简介对自身设计的描述，并不等于已证明其覆盖面或性能优于其他方案。README 给出的性能实例仅为 Dreaming Sarah 在 GTX 1050 Ti 与 i5-7500 3.4GHz 上稳定运行于 60 fps；该单一案例不能代表其他游戏或硬件表现。

## 值得关注的设计
