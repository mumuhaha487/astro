Pyxel 是一款用 Rust 构建的 Python 复古游戏引擎，受经典游戏机启发，仅支持 16 色显示和 4 个音效通道，便于轻松制作像素风格游戏。项目开源，由个人开发维护。

## 项目做什么

Pyxel 的主要目标是让使用 Python 的开发者能够轻松、愉快地制作像素艺术风格的复古游戏。通过模仿早期游戏机的硬件限制，如仅 16 种颜色和 4 个声音通道，它降低了游戏开发的复杂度，使创作者可以专注于游戏玩法和像素艺术本身，而不是处理复杂的图形或声音系统。该项目面向希望快速入门游戏开发或重温复古游戏体验的 Python 程序员。
