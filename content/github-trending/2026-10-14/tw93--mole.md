Mole 是面向 macOS 的开源命令行工具，提供清理、卸载、系统维护、磁盘分析与实时状态查看等功能；另有独立的原生 Mac 应用，但通过 Homebrew 安装的是命令行版本。

## 项目做什么

项目旨在通过统一的终端界面管理 Mac 上的常见维护任务。用户可清理缓存、日志和已卸载应用残留，卸载应用及可关联文件，运行部分系统维护操作，交互式检查磁盘占用，并查看 CPU、内存、磁盘、网络和进程信息。README 称最低要求为 macOS 12，支持 Intel 与 Apple Silicon。

## 与同类方案相比

README 展示了多类操作的预览模式、操作记录、白名单和确认流程，帮助用户在删除前检查范围；工具也说明会保护共享或系统位置，并在无法确认安全时跳过或拒绝操作。分析与状态命令可输出 JSON，便于脚本读取；卸载时默认保留个人数据，且文档说明共享数据会在仍被其他应用使用时保留。以上为项目文档描述，实际效果需在目标系统上核实。

## 设计与创新

README 将清理、卸载、维护、磁盘分析和状态监控整合到一个 CLI，并提供交互式终端界面与机器可读输出。文档还描述了磁盘扫描完整性状态、状态采集时间及旧记录归因不确定性的表达方式。不过，现有材料不足以证明这些设计属于行业首创，也没有可核验的横向比较或技术评测，因此创新程度尚无法判断。

## 适用场景

适用于希望从终端清理 Mac 缓存和应用残留、检查大文件或目录、卸载应用、刷新部分系统缓存与服务，以及查看设备资源和网络活动的个人用户。开发者也可用 purge 检查项目构建产物，或利用 JSON 与 NDJSON 接入脚本。外接磁盘可指定路径分析；涉及删除的操作宜先运行 dry-run，并核对预览和日志。

## 谁会受益

对于需要定期维护 Mac、希望在终端完成多项检查，或需要结构化状态和磁盘数据的用户，Mole 可提供一组集中入口，减少在不同维护任务间切换工具的需要。其价值取决于用户是否需要这些功能以及扫描结果是否符合预期；README 未提供独立测试、准确率或节省时间等证据，不能据此量化实际收益。

## 使用前需要注意

该项目的命令行版本面向 macOS，README 标明要求 macOS 12 或更新版本；Windows 内容链接到单独分支，不能据此确认主仓库 CLI 的跨平台支持。清理和卸载可能删除文件，用户需审查预览并承担操作风险；磁盘扫描可能因权限、超时或排除规则而不完整。原生 Mac 应用是另行下载的软件，不应与 Homebrew 安装的 CLI 混为一谈。
