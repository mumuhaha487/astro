PentAGI 是以 Go 为主要语言的自托管多智能体渗透测试系统，用户可用自然语言描述目标和任务，由专门代理规划并调用隔离环境中的安全工具执行测试。

## 项目做什么

项目面向安全工程师、渗透测试人员、研究者及红队，旨在协助开展经授权的渗透测试。系统将任务描述交给多智能体流程处理，可使用安全工具、搜索服务和语言模型收集信息、执行测试并生成报告；README 明确指出，它不是带有预定义攻击计划的 BAS 或对手模拟产品。

## 与同类方案相比

从 README 所列功能看，项目提供自托管部署、Docker 沙箱、多个 LLM 提供方及兼容端点、REST 与 GraphQL API，并可保存任务记录和研究结果。它还描述了可选知识图谱、监控与报告能力。这些是文档列出的设计和功能，实际隔离强度、可靠性与运行成本仍需部署和测试验证。

## 设计与创新

README 强调的组合包括多智能体协作、执行监控与任务规划、长期记忆，以及可选的 Neo4j 知识图谱；同时支持多种云端或本地模型配置。但材料不足以证明这些机制在技术上具有独创性，也没有提供与其他系统的对照评测，因此不能据此断言其创新程度或比较优势。

## 适用场景

较适合在获得明确授权的前提下，用于安全团队的测试辅助、研究环境中的渗透测试流程探索，以及将任务接入自动化系统。自托管和 API 能用于按需集成；若使用外部模型或搜索服务，还需结合组织的数据管理要求评估配置。它不应被误作已有预定义攻击活动的 BAS 平台。

## 谁会受益

对于希望把自然语言任务、工具执行、结果留存和报告流程放在同一套系统中的团队，PentAGI 可作为实验或工作流辅助工具。工具目录、模型选项、持久化存储和 API 描述提供了初步集成依据；具体能否减少人工工作、发现问题或适配现有流程，仍取决于模型、配置、目标环境与人工复核。

## 使用前需要注意

README 的功能说明不能替代独立安全审计或实测，未能据此确认代理输出准确率、工具覆盖质量、沙箱边界强度和扩展后的运行表现。自主测试可能产生误判或影响目标系统，必须严格限定授权范围并审查执行结果。文档还指出，当前产品不是 BAS，代理编写攻击脚本属于概念或未来工作，流报告也未说明支持 JSON 导出。
