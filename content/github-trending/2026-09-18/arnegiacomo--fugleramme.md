Fugleramme 是面向树莓派的电子墨水观鸟画框：用本地音频实时识别鸟种，再把十九世纪手工剪裁的鸟类插画拼版展示出来，也可只以网页 kiosk 形式运行，无需墨水屏。

## 项目做什么

项目想解决的是把自家院子里实际听到的鸟直接呈现在墙上这个问题。README 说明，作者受一幅 WWF 自然海报启发，又看到 AvianVisitors 的实时画框和 BirdNET-Go 的识别能力，于是想做一版展示自己花园真实鸟种的海报。因此它的目标不是做通用鸟类识别工具，而是做一个长期挂在厨房窗台、平时不用干预、只在鸟种变化时更新画面的展示设备，同时保留网页视图，方便没有墨水屏的人先试用。

## 与同类方案相比

按照 README 描述，它复用 BirdNET-Go 完成音频监听与分类，自己不重复实现模型，因此已运行 BirdNET-Go 的用户可以直接把画框指向已有实例，无论在同一个树莓派还是网络内其他机器上。安装方式较为完整，提供 install.sh 的 systemd 服务安装、Docker 镜像运行以及带 USB 麦克风的 docker compose 示例；开发环境用 uv 加假检测器就能在没有硬件的情况下跑起来。项目自称准备了超过 800 张剪裁、覆盖 400 多个物种，并提供管理页面配置显示内容。作者也提示项目仍处早期开发，因此这些便利性尚未经过独立的可靠性验证。

## 设计与创新

较为特别的一点是美术路线：插画全部取自公共领域的真实自然史图谱，由人工逐张抠图整理，项目明确说明没有一张是 AI 生成的，只有部分经过 AI 修图。拼版逻辑上，每张图按体重决定尺寸并让较大的鸟更靠近中心，空窗口时显示一根光秃的栖枝，形成海报式的版面。渲染上只在鸟种发生变化时才重绘，符合电子墨水的刷新特点，并让墨水屏与网页 kiosk 呈现同一视图。README 提到同类项目有若干，但明确表示不共享任何代码或美术资源，因此创新程度与相对优势尚无第三方对比可以验证。

## 适用场景

典型场景是在厨房或窗边摆一个 A4 画框：树莓派 5 加 Inky Impression 13.3 英寸墨水屏、一个麦克风，由 BirdNET-Go 持续监听，画框轮询其接口并更新画面。没有墨水屏时项目也能运行，只提供网页视图，可以在 HDMI 显示器上做 kiosk，或从局域网内任意设备打开。已有 BirdNET-Go 的用户可以直接对接现有站点。在带 USB 麦克风的 Linux 机器上，官方 compose 示例会一并拉起 BirdNET-Go。地域上，由于图版来自斯堪的纳维亚、英国和中欧，这几处覆盖最好，其他地区有限。

## 谁会受益

对观鸟爱好者、喜欢 DIY 电子墨水装置的制作者，以及希望识别完全在本地运行、不依赖云端服务的人，这个项目提供了可直接照做的安装路径和较完整的配套文档，包括硬件清单、安装、容器、加图集与贡献说明，还有可搜索的物种覆盖列表。开发时可用假检测器在没有树莓派的情况下验证界面与流程，降低了试错成本。README 提到提供管理页面用于配置显示内容，并支持自动更新。不过其实际识别准确率、刷新耗时、长期运行稳定性均未在 README 中给出数据，实用性只能从功能描述判断，无法量化。

## 使用前需要注意

项目明确标注仍在早期开发，作者提示会遇到 bug 和一些未打磨之处，后续还会有更多功能。物种覆盖存在明显地域偏向：北欧、不列颠群岛和德国最好，其他地区覆盖有限，更广的欧洲与北美覆盖只说在计划中。识别能力完全依赖外部 BirdNET-Go 组件，该组件以 CC BY-NC-SA 4.0 授权，仅限非商业用途，使用者需自行遵守；代码为 MIT，经典风格美术为 CC BY-SA 4.0，字体为 SIL OFL 1.1。此外作者表示目前没有余力为他人代做画框。项目未公布性能、准确率或与其他同类项目的实测比较。
