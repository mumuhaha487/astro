Claude Code 是 Anthropic 推出的终端智能编码工具，可用自然语言执行例行编码任务、解释复杂代码并处理 Git 工作流，支持在终端、IDE 中使用，也可在 GitHub 上通过 @claude 调用。

## 项目做什么

该项目旨在让开发者在终端环境中用自然语言驱动 agent 完成编码相关工作，README 明确列出三类用途：执行例行任务、解释复杂代码以及处理 Git 工作流。同时仓库包含若干插件，用于通过自定义命令和 agent 扩展功能，具体说明需查看 plugins 目录文档。安装方面，README 指出 npm 安装已弃用，推荐使用安装脚本、Homebrew、WinGet 等方式，并要求 Node.js 18 及以上版本。

## 与同类方案相比

从 README 可确认的特点包括：使用入口较多，既可在终端运行，也可在 IDE 中使用，还能在 GitHub 上通过 @claude 触发；安装渠道覆盖 macOS、Linux 与 Windows，提供 curl 脚本、Homebrew、PowerShell 脚本和 WinGet 等选择；提供插件机制以扩展自定义命令与 agent；设有 /bug 命令和 GitHub issue 两条问题反馈渠道，并有 Discord 社区。README 还声明了敏感信息有限保留期、会话数据访问受限以及不将反馈用于模型训练等隐私保护措施，但这些属于文档声明，未提供第三方验证细节。
