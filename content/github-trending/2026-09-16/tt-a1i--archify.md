Archify 是面向 Cursor、Claude Code 等编程代理的 Node.js 技能，将代理生成的类型化 JSON IR 确定性编译为自包含 HTML 系统图并校验导出。

## 项目做什么

把代码库或系统的文字描述转换成可交互、可分享的系统图，降低手工绘图与对齐成本。代理负责产出类型化 JSON IR，Archify 负责确定性编译、布局与校验，覆盖架构、工作流、时序、数据流和生命周期五类图，并在交付前做 schema、布局、HTML/SVG、路由与标签避让检查，借此支持在合并前比对架构变更、在文档和评审中复用同一份经过验证的产物，也可以在不打开任何仓库的情况下仅凭对话描述出图。

## 与同类方案相比

据 README 描述，布局由代理判断层级、间距、路由与强调，共享自动端点按确定性方式散开，而不是把箭头堆在同一中点；每种渲染模式都有 schema 与可复现来源；交付采用原子校验，只有通过全部检查的候选产物才会替换上一个已知良好输出；校验与交付失败时返回稳定规则码、具体对象、实测证据和受支持的修复项，而不是 Node 堆栈；可选预览只在回环地址监视单个 JSON 文件，失败时保留上一份已验证图；交互只复用已编写的节点与关系，不外推拓扑，也不声称运行时影响；导出为单个 HTML 文件，且不含临时查看器状态。

## 设计与创新

可确认的设计点包括：以类型化 JSON IR 作为唯一事实来源并确定性编译到 HTML/SVG；把 schema、布局、产物、路由、标签避让合并为交付前必须通过的原子校验门；失败时给出机器可读的修复回执与受支持修复项，并限定修正轮次；提供 Before、Delta、After 三态快照比对及机器回执，逐项列出新增、删除、变更、移动和改道事实；在明确请求时才生成标记为 SRC n 的证据节点并链接到固定提交的 Git 文件与行号；为路由和下上游可达范围导出 1200×630 分享卡。这些是否在同类工具中首创，README 未给出对照依据，无法验证。

## 适用场景

适用于需要在评审或沟通中快速说明结构的场合：提交 PR 前比对两份架构快照，查看新增、删除、变更与移动的事实；为新成员讲解系统组成、信任边界与主路径；在对话中描述浏览器到 API 到缓存到数据库的链路并直接出图，无需现成仓库；绘制 CI/CD 校验、审批、部署与回滚流程；绘制 API 调用、缓存回退、鉴权等时序交互；绘制数据管道、血缘与敏感数据边界；绘制状态机的重试、等待与终止状态；用演示模式逐章讲图；把图导出为 PNG、SVG、WebM 或分享卡用于发布说明与文档页面。

## 谁会受益

对工程师、技术负责人和文档维护者而言，主要价值是把技术意图固定成可检查、可复现、可分发的单一 HTML 产物，并附带验证回执与稳定链接，例如按 id 恢复聚焦、可达范围、路由、角色对比和命名视图。命令行支持 doctor、demo、guide、validate、preview、deliver、compare 等操作，可脱离代理单独调用；页面支持明暗主题、四套预设、内置品牌标记、有限动效与降低动效偏好、键盘快捷键、搜索与角色对比，并可通过 locale 设置本地化页面标题、图例、状态与无障碍信息，而作者编写的内容保持原样。

## 使用前需要注意

README 标注当前为开发版本 v2.17.0-dev.1，接口与行为仍可能变动。工具依赖 Node.js 以及把技能安装进各代理的指定目录，不同接入方式能力描述基本相同但安装路径各异。图形质量取决于代理是否给出结构正确的 JSON IR，布局判断也由代理承担。架构模式的部署归属配置不检查真实基础设施，缺失作者声明的负责人、区域、私有数据库范围或命名跨越时会失败关闭；整体也不对运行时影响、风险或合并安全性作判断。默认更新检查会向固定清单发起 HTTP GET，可设置环境变量关闭。README 未提供性能数据，也未与其他绘图工具做可验证对照，因此相对优势与创新程度暂时无法核实；此外校验只能证明产物满足既定规则，不能证明所描述的系统本身正确。
