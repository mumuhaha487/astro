T3 Code 是用于远程控制本机 AI 编程代理的应用，提供移动端、网页端和桌面端入口，并要求先安装或配置至少一个受支持的代理。

## 项目做什么

项目定位为代理控制界面，让用户通过手机、浏览器或桌面应用操作本机已安装和认证的编程代理。README 列出的支持对象包括 Codex、Claude Code、Cursor、Grok Build、OpenCode 和 Google Antigravity；它并非这些代理本身，使用前需分别完成相应的安装或登录设置。

README 所能确认的便利之处是提供多种访问入口，并允许通过命令行启动本地网页应用、安装后台服务或使用桌面安装包；文档还涉及远程访问、项目设置、权限模式和版本同步。实际易用性、速度、稳定性及与各代理的兼容范围，不能仅凭简介和 README 独立验证。

## 适用场景

适用情形包括：开发者希望从手机或另一台机器访问工作电脑上的代理，或在网页、桌面界面中统一操作已配置的多个代理；也可按需将服务作为后台进程运行。是否适合特定团队、工作流或安全要求，还需结合远程访问文档和实际部署方式评估。

## 谁会受益

如果用户已经在电脑上安装并登录 README 所列代理，T3 Code 可提供集中控制入口，并通过安装脚本、npx 临时运行或桌面安装包开始使用。文档提及源代码管理集成、快捷键、外观和多账户等主题，可能有助于日常配置；这些主题的具体能力与适用限制仍应查阅对应文档确认。
