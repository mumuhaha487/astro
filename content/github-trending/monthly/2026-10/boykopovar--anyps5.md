AnyPS5 是一个以 C++ 编写的 PS5 可执行文件移植工具，目标是在 Linux 和 Windows 上运行相关程序；项目以重链接器和系统库实现为核心，并明确表示不依赖模拟或独立运行时进程。

## 项目定位与要解决的问题

项目定位在 PS5 可执行文件与桌面操作系统之间提供移植层，而非把主机环境完整封装成模拟器。README 将其概括为自动移植工具，并指出它包含将可执行文件转换为目标系统原生格式的重链接器，以及供动态链接使用的系统 PRX 库实现。由此可见，项目要处理的不只是文件格式转换，也包括程序运行时对系统接口的依赖。其目标平台是 Linux 和 Windows；但简介没有说明支持的具体可执行文件范围、主机型号限制或各平台的完成程度，因此不能据此推断所有 PS5 程序都能运行。

## 核心能力

核心组成有两部分：重链接器负责将输入可执行文件转换为目标系统的原生格式；PRX 库实现则为程序动态链接时所需的系统库功能提供对应实现。项目还包含着色器重编译器，README 表示它可以生成 SPIR-V，并可在启用 ANYPS5_ENABLE_SPIRV_TOOLS 时通过 Spirv-Tools 验证。项目披露的状态指标需要谨慎理解：系统库百分比只统计项目目前已声明函数中的已知部分，不代表对 PS5 全部系统函数的覆盖率，而且统计总量会随新增声明而增长。未支持或意外状态会抛出 std::runtime_error，将错误信息输出到标准错误后终止进程。

## 技术结构与实现思路

从 README 提供的结构看，AnyPS5 将可执行文件重链接、系统库替代实现和着色器重编译纳入同一移植方案：前者面向目标格式，PRX 实现面向动态链接依赖，着色器组件负责产生 SPIR-V。项目方明确称该方案不使用模拟，也不另起独立运行时进程；这是其架构选择的直接描述，但 README 未交代重定位规则、系统调用映射、内存管理、线程模型或图形接口的具体设计，不能补写这些实现细节。文档入口分别提供用户使用说明、构建说明、架构说明、技术债务、代码风格和贡献指南，显示项目将使用、开发和未完成事项作为不同主题维护。

## 实际工作流程

依据项目简介，运行路径可概括为：准备待移植的可执行文件，由重链接器将其转换成目标系统原生格式，再通过项目实现的 PRX 系统库满足程序的动态链接需求；涉及着色器时，相关组件生成 SPIR-V，且可按构建选项启用 Spirv-Tools 校验。用户可进一步查阅 README 链接的 USAGE 文档了解实际操作，构建则有单独的开发说明。输入控制方面，项目支持 SDL 映射的游戏控制器，包括摇杆和扳机；键盘与鼠标可通过 anyps5-input.ini 配置。现有信息没有给出命令行参数、依赖安装步骤或完整运行前提，实际操作应以项目使用文档为准。
