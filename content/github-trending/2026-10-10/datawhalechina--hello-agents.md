Hello-Agents 是 Datawhale 社区整理的中文智能体学习教程，按基础、构建、高级技术和综合案例分阶段讲解，配有代码与在线阅读入口，面向希望理解原理并动手开发 AI 原生智能体的学习者。

## 项目做什么

项目旨在提供从概念到实践的智能体系统学习路径，重点讲解以大语言模型驱动的 AI 原生智能体，而非仅介绍流程编排。内容从智能体和语言模型基础出发，覆盖经典范式、平台与框架使用、自建框架、记忆检索、上下文工程、通信协议、训练和评估，并以多个综合项目收束。

## 与同类方案相比

教程提供中文内容、分阶段章节和多种学习材料入口，覆盖从原理、单智能体构建到多智能体综合案例的多个环节。README 说明项目免费开放阅读，并鼓励读者运行和修改配套代码、提交问题或贡献内容。相较单一工具教程，它的主题范围更宽；但是否更适合某位读者，仍取决于其基础、目标和具体章节质量。

## 设计与创新

README 将项目定位为从核心原理出发、兼顾框架使用与自建实现的系统教程，并安排了从 ReAct 等范式到多智能体案例的学习链路。它还把记忆、上下文工程、协议、Agentic-RL 和评估纳入同一课程体系。不过，README 未提供与其他教程的对照评测或可验证的独有方法，因此无法据此确认其相较已有资源的创新程度。

## 适用场景

适用于具备基础 Python 能力、了解如何通过 API 调用大语言模型的学习者，用于自学智能体概念、复现经典构建范式、熟悉低代码平台和开发框架，或练习从零搭建智能体应用。课程案例包括智能旅行助手、自动化深度研究智能体、赛博小镇和毕业设计；也可作为教学讨论或社区共创的参考材料。

## 谁会受益

对于希望由模型 API 使用者转向智能体应用构建者的人，教程提供了相对连续的知识路线、实践代码和综合项目方向，可用于安排阶段性学习与练习。章节涉及多种工具、框架和技术主题，读者可按需求选读或循序完成。项目也列出面试相关补充材料，但教程是否能满足特定岗位或项目要求，需要结合读者基础和实际任务判断。
