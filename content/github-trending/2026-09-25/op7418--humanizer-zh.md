这是一个面向 Claude Code 的中文文本润色 Skill，输入文字或文件，按编辑原则去除空话、重复与模板化表达，同时保留事实、确定程度和作者声音，默认交付最终稿而非检测报告。

## 项目做什么

项目目的是为中文写作提供一份由 Agent 读取执行的编辑指导，用于改写已有文章、评论和文档中的空话、重复和模板化表达。它明确自身不是独立检测程序，无法证明文章作者身份，也不保证通过任何 AI 检测器。使用方式包括粘贴文本、编辑文件，或仅要求给出建议而不修改文件；有作者样本时可提供以借鉴表达习惯，但不会把样本中的经历、数据或观点搬入原文。

## 与同类方案相比

该项目强调改写时保留信息与确定程度，不编造功能、数据、来源、人物身份或第一人称经历，并保留否定、条件、归因、范围、时间和完成状态。它按作用判断三项列表、四字格、被动句、破折号和连接词，不机械删除，也根据文体保留个性与正式程度。文件编辑默认保留代码、命令、路径、链接目标、YAML、数据、标题和锚点，改标题或结构需检查引用，这些约束在 README 中有明确说明。

## 设计与创新

项目在原版 A–E 分类基础上增加了 F 类中文补充检查，共 31 个检查点，涵盖长定语、进行加动词、被字句堆叠、四字词排比、万能背景和套话收尾等中文特有问题。更新说明称重写了规则和示例，明确保留事实、作者立场和文体，普通排比、破折号和连接词不再一律修改。但相对原版和其他工具的具体效果差异，README 未提供对照数据，尚无法验证。

## 适用场景

适用于编辑已有文章、技术评论和文档，例如在保留技术评论语气的前提下润色正文，或对 Markdown 文件的正文进行改写。示例覆盖产品介绍缺少数据、故障反馈带有不确定性、更新说明含真实三项功能，以及已经清楚的文字无需修改等情况。也可用于只审阅、给出建议而不修改文件，或在提供作者样本时借鉴其表达习惯。其定位是编辑辅助，不适合作为作者身份判定或 AI 检测依据。

## 谁会受益

项目提供了相对完整的使用说明、安装方式、改写示例和模式目录，规则条目以检查点加修改条件、前后示例和保留边界的形式组织，便于对照执行。约束优先级明确为保留信息和确定程度、遵守用户范围与文体、匹配作者声音，再处理具体表达问题，模式命中不能覆盖这些要求。测试说明包含 18 个短文本案例、一个 Markdown 文件样例和结构检查脚本，并做了旧版与修订版的长文对照，为使用者提供了可自行核验的基础。

## 使用前需要注意

项目自述是一份由 Agent 读取执行的编辑指导，不是独立的检测程序，不能证明文章由谁撰写，也不保证通过任何 AI 检测器。测试为单次、有限样例，作者明确说明不能代表所有模型和文体，也不能用字数下降或模型自评分证明效果。改写效果依赖所用模型、提示和具体文体，README 未给出可量化的效果数据；原版与本项目新增中文检查点之间的实际增益，以及与其他工具的比较，均缺少依据，尚无法验证。
