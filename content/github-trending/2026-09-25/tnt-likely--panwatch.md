盯盘侠 PanWatch 是一个自托管的 AI 盯盘助手，集成 TradingAgents 多 Agent 框架，覆盖 A 股、港股、美股实时监控、持仓管理与分析，并通过多渠道推送通知。

## 项目做什么

该项目旨在为个人投资者提供一套可自行部署的智能盯盘解决方案，通过整合多市场行情、持仓管理、技术指标分析与 AI 决策能力，帮助用户自动化监控自选股动态、获取盘前盘后分析报告，并在价格条件触发或 AI 识别出关键信号时，通过多种即时通讯渠道推送提醒，降低人工盯盘的精力消耗。

## 与同类方案相比

PanWatch 采用自托管部署方式，用户数据存储于本地，不经过第三方服务器，强调数据私有性。它提供 Docker 一键部署方案，内置对 A 股、港股、美股的多市场支持，并集成了 TradingAgents 多 Agent 投资决策框架，能够输出包含分析师辩论、风控审查和 PM 决策的完整推理链。此外，项目支持 Telegram、企业微信、钉钉、飞书、Bark 及自定义 Webhook 等多种推送渠道，并允许用户按交易风格分别设置账户，使得 AI 建议更贴合个人需求。

## 设计与创新

项目的主要创新点在于将 TradingAgents 的多 Agent 决策机制引入到个人盯盘工具中，实现了从触发分析到生成包含多空辩论和风控审查的决策书，并同步推送至 IM 的完整流程。同时，项目内建了结构化日志、运行表及节点级进度与成本追踪的自建可观测体系，并可选地支持 OpenTelemetry 标准导出，便于对接 Jaeger、Tempo 等 APM 系统。此外，其价格提醒功能支持多条件组合、冷却时间、日触发上限等细致规则。

## 适用场景

适合需要同时关注 A 股、港股、美股多个市场的个人投资者，用于日常盯盘、持仓管理与机会挖掘。用户可在盘前获取综合隔夜美股和新闻的当日策略，盘中接收技术指标共振或价格异动提醒，盘后查看复盘日报。对于偏好自动化推送的用户，可通过配置通知渠道，将 AI 分析结论和价格触发提醒发送至常用 IM。也适用于希望自行托管服务、对数据隐私有要求的用户。

## 谁会受益

该项目能帮助投资者自动化执行盯盘任务，减少手动查看行情的时间，通过 AI 分析提供多角度的决策参考，如技术指标、新闻情绪和基本面。价格提醒的条件组合和冷却机制可避免过度打扰。集成 TradingAgents 后，用户能在持仓页一键触发深度分析，获得包含多空辩论的推理链，并直接推送到 IM，提升了信息获取效率。对于技术用户，自托管方式便于数据掌控和二次开发。

## 使用前需要注意

项目依赖用户自行配置 AI 服务商 API（如 OpenAI、DeepSeek 等）和通知渠道，首次部署和配置有一定门槛。虽然 Docker 镜像已包含 Playwright 依赖，但 Chromium 浏览器首次启动时需自动下载，可能耗时且依赖网络。AI 分析结果的准确性和可靠性未在 README 中提供数据验证，其投资建议仅供参考。此外，项目未声明支持的市场数据源是否覆盖全部股票，实时行情可能存在延迟或受限。对于非技术用户，本地开发环境要求 Python 和 Node.js，可能不够友好。
