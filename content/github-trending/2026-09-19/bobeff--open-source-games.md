该仓库以 README 清单形式汇总开源电子游戏与商业游戏的开源重制、复刻及逆向工程源码项目，按玩法类型分类整理，并为每个条目提供官网与源码链接。

## 项目做什么

仓库目的是充当开源游戏领域的目录与导航：把分散在不同托管平台（GitHub、GitLab、Codeberg、SourceForge 等）的开源游戏、商业游戏复刻、源码移植和反编译项目按类型归类，方便玩家、开发者与研究者快速检索可玩、可修改或可研读源码的项目，降低逐个搜索的成本，并呈现开源游戏生态的概貌。

## 与同类方案相比

条目按动作、冒险、经营、城市建造、第一人称射击、平台跳跃、解谜、竞速等类型分组，覆盖面较广，既包含 id Software 经典作品的开源发布，也包含 OpenTTD、OpenRCT2、ScummVM 等知名复刻或兼容层。多数条目给出简介、官网和源码链接，部分标注所用引擎，便于按兴趣浏览和对比同一原作的不同实现。但这些属于信息组织层面的便利，README 未提供性能、许可证或维护状态等可验证指标。

## 设计与创新

作为清单型仓库，其创新更多体现在整理与聚合：将商业游戏逆向工程、反编译和源码移植项目（如《塞尔达传说：黄昏公主》反编译、Super Mario 64 反编译、OpenGOAL 等）与传统开源游戏并列呈现，并细化到子类别，例如把 Build 引擎、id Software 游戏及其源码移植单独分节。不过 README 未说明收录标准、审核流程或更新机制，因此无法确认这种分类框架是否具有原创设计，也难以验证它相较其他同类清单的独特贡献。

## 适用场景

适合玩家查找可免费游玩或自由修改的开源游戏；适合开发者寻找参考实现、游戏引擎、反编译或逆向工程项目进行学习与二次开发；适合研究者或内容创作者了解开源游戏生态、商业游戏保存与复刻现状；也可作为教学案例库或二次整理的数据来源。但需注意，给定 README 文本在竞速游戏章节处截断，实时战略、Roguelike、角色扮演、沙盒、射击、体育、第三人称、塔防和回合制战略等章节内容未完整呈现，引用前应核对原始仓库。

## 谁会受益

对需要快速定位开源游戏项目的人具有直接参考价值：条目提供官网与源码仓库链接，可减少跨平台搜索时间；按类型分组便于按兴趣筛选；对同一原作列出多个源码移植时，读者可据链接进一步比较。但 README 本身不提供项目活跃度、许可证、平台支持、版本号或可玩性评价，使用者仍需跳转核实。此外，仓库语言标记为 Python 与内容为文档清单存在不一致，可能影响自动化分类与检索。
